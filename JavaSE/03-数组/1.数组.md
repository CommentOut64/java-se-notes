## 1. 一维数组

### 1.1. 数组的声明与初始化

- 数组是存储**相同类型**数据的**有序**集合。
- 数组也是对象，数组元素相当于对象的**成员变量**。

**1. 声明数组**

在 Java 中声明数组时不能指定其长度。

```java
// 推荐写法
元素类型[] 数组名;

// 示例
int[] scores;
String[] names;
```

**2. 初始化数组**

数组的初始化分为静态初始化和动态初始化。

*   **静态初始化**：在定义数组的同时为数组元素分配空间并赋值。数组长度由静态数据的个数决定。

    ```java
    // 格式1：完整格式
    数据类型[] 数组名 = new 数据类型[]{元素1, 元素2, ...};
    // 示例
    int[] arr = new int[]{1, 2, 3, 4, 5};
    
    // 格式2：简化格式 (声明和初始化必须在同一行完成)
    数据类型[] 数组名 = {元素1, 元素2, ...};
    // 示例
    int[] arr = {1, 2, 3, 4, 5}; 
    ```

*   **动态初始化**：初始化时只指定数组长度，由系统为数组分配初始值。

    ```java
    // 格式
    数据类型[] 数组名 = new 数据类型[长度];
    // 示例
    int[] arr = new int[5]; // 创建一个长度为5的int数组
    ```
    > **注意**：数组具有定长特性，长度一旦指定，不可更改。静态初始化和动态初始化不能混合使用，例如 `new int[5]{1,2,3,4,5};` 是非法的。

### 1.2. 数组的基本使用

*   **获取数组长度**：通过 `length` 属性可以获取数组的长度。
    
    ```java
    int[] arr = {1, 2, 3, 4, 5};
    System.out.println("数组长度: " + arr.length); // 输出 5
    ```
*   **访问数组元素**：通过 `数组名[索引]` 的方式访问。索引从 `0` 开始，最大到 `数组长度 - 1`。
    
    ```java
    int[] arr = new int[3];
    arr[0] = 100; // 为第一个元素赋值
    arr[1] = 200;
    System.out.println("第一个元素: " + arr[0]); // 读取第一个元素的值
    ```

### 1.3. 数组的遍历

遍历是指依次访问数组中的每一个元素。

```java
public class ArrayTraversal {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5};

        // 方法一：传统 for 循环
        System.out.println("使用传统 for 循环遍历：");
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();

        // 方法二：增强 for 循环 (for-each)
        System.out.println("使用 for-each 循环遍历：");
        for (int element : arr) {
            System.out.print(element + " ");
        }
        System.out.println();
    }
}
```

### 1.4. 数组元素的默认值

使用动态初始化创建数组时，其元素会被赋予默认值。

| 数据类型 | 默认值 |
| :--- | :--- |
| `byte`, `short`, `int`, `long` | `0` |
| `float`, `double` | `0.0` |
| `char` | `'\u0000'` (空字符) |
| `boolean` | `false` |
| 引用类型 (如 `String`) | `null` |

```java
// 示例：
int[] a = new int[5]; 
System.out.println(a[3]); // a[3] 的默认值为 0

String[] names = new String[5];
System.out.println(names[0]); // names[0] 的默认值为 null
```

## 2. 二维数组

二维数组本质上是元素为一维数组的一维数组。

### 2.1. 二维数组的声明与初始化

**1. 声明**

```java
元素类型[][] 数组名;
```

**2. 静态初始化**

```java
// 完整格式
int[][] arr = new int[][]{{3,8,2}, {2,7}, {9,0,1,6}};

// 简化格式
int[][] arr = {{3,8,2}, {2,7}, {9,0,1,6}};
```

**3. 动态初始化**

*   **规则数组** (每行列数相同)
    
    ```java
    // 格式：new 元素类型[行数][列数];
    int[][] arr = new int[3][4]; // 3行4列的数组
    ```
    
*   **不规则数组** (每行列数不同)
    ```java
    // (1) 先确定行数
    int[][] arr = new int[3][];
    
    // (2) 再为每一行单独指定列数
    arr[0] = new int[3];
    arr[1] = new int[1];
    arr[2] = new int[2];
    ```
    > **注意**：不能只指定列数而不指定行数，例如 `new int[][3];` 是非法的。

### 2.2. 二维数组的使用

*   **获取行数**：`数组名.length`
*   **获取某行的列数**：`数组名[行索引].length`
*   **访问元素**：`数组名[行索引][列索引]`

```java
int[][] scores = {
    {85, 96, 85},
    {99, 96, 74, 72},
    {52, 42}
};

System.out.println("总共有 " + scores.length + " 组。"); // 3
System.out.println("第2组有 " + scores[1].length + " 个学员。"); // 4
System.out.println("第1组第2个学员的成绩是: " + scores[0][1]); // 96
```

### 2.3. 二维数组的遍历

通常使用嵌套的 `for` 循环遍历二维数组。

```java
int[][] scores = {{85, 96}, {99, 74}, {52, 42}};

for (int i = 0; i < scores.length; i++) { // 遍历行
    System.out.print("第" + (i + 1) + "组成绩: ");
    for (int j = 0; j < scores[i].length; j++) { // 遍历列
        System.out.print(scores[i][j] + "\t");
    }
    System.out.println();
}
```

## 3. 数组的常见操作与算法

### 3.1. 数组元素的查找

*   **顺序查找 (Linear Search)**
    从头到尾依次比较，直到找到目标元素或遍历结束。

    ```java
    int[] arr = {4, 5, 6, 1, 9};
    int target = 6;
    int index = -1; // -1表示未找到
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            index = i;
            break; // 找到后退出循环
        }
    }
    System.out.println("目标元素的索引: " + index); // 输出 2
    ```

*   **二分查找 (Binary Search)**
    **前提：数组必须是有序的。** 通过比较中间元素与目标值，每次将查找范围缩小一半。

    ```java
    // 数组必须有序
    int[] arr = {-99, -54, -2, 0, 2, 33, 43, 256, 999};
    int target = 43;
    int head = 0; // 首索引
    int end = arr.length - 1; // 尾索引
    int index = -1;
    
    while (head <= end) {
        int middle = (head + end) / 2;
        if (arr[middle] == target) {
            index = middle;
            break;
        } else if (arr[middle] > target) {
            end = middle - 1; // 排除已检查的 middle 位置
        } else { // arr[middle] < target
            head = middle + 1; // 排除已检查的 middle 位置
        }
    }
    System.out.println("目标元素的索引: " + index); // 输出 6
    ```

### 3.2. 数组的排序

*   **冒泡排序 (Bubble Sort)**
    重复地遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。

    ```java
    int[] arr = {22, 33, 11, 55, 44};
    for (int i = 0; i < arr.length - 1; i++) {
        for (int j = 0; j < arr.length - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换元素
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
    // 排序后 arr 为 {11, 22, 33, 44, 55}
    ```

### 3.3. 数组元素的统计

计算数组的最大值、最小值、总和、平均值等。

```java
int[] arr = {4, 5, 6, 1, 9};
int max = arr[0];
int min = arr[0];
int sum = 0;

for (int i = 0; i < arr.length; i++) {
    if (arr[i] > max) {
        max = arr[i];
    }
    if (arr[i] < min) {
        min = arr[i];
    }
    sum += arr[i];
}

double avg = (double) sum / arr.length;

System.out.println("最大值: " + max); // 9
System.out.println("最小值: " + min); // 1
System.out.println("总和: " + sum); // 25
System.out.println("平均值: " + avg); // 5.0
```

### 3.4. 数组的复制、扩容与缩容

数组的长度不可变，扩容和缩容本质上是创建一个新数组，然后将原数组的元素复制过去。

*   **扩容**：创建一个更大的新数组，复制原数组元素。
    
    ```java
    int[] oldArr = {1, 2, 3};
    int[] newArr = new int[oldArr.length * 2]; // 长度加倍
    
    for (int i = 0; i < oldArr.length; i++) {
        newArr[i] = oldArr[i]; // 复制元素
    }
    oldArr = newArr; // 将引用指向新数组
    ```
    
*   **缩容**：创建一个更小的新数组，复制所需元素。
    
    ```java
    int[] oldArr = {1, 2, 3, 4, 5};
    int delIndex = 2; // 要删除的索引
    int[] newArr = new int[oldArr.length - 1];
    
    for (int i = 0, j = 0; i < oldArr.length; i++) {
        if (i != delIndex) {
            newArr[j++] = oldArr[i];
        }
    }
    oldArr = newArr; // 最终 oldArr 为 {1, 2, 4, 5}
    ```

### 3.5. 数组元素的反转

通过首尾元素对称交换实现。

```java
int[] arr = {1, 2, 3, 4, 5};
for (int left = 0, right = arr.length - 1; left < right; left++, right--) {
    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;
}
// 反转后 arr 为 {5, 4, 3, 2, 1}
```

## 4. `java.util.Arrays` 工具类

`java.util.Arrays` 类提供了大量操作数组的静态方法，简化了开发。

| 方法签名 | 功能描述 | 参数说明 |
| :--- | :--- | :--- |
| `static String toString(int[] a)` | 返回数组内容的字符串表示形式，如 `[元素1, 元素2, ...]`。 | `a`: 要转换的数组。 |
| `static void sort(int[] a)` | 对数组进行升序排序。(双轴快速排序) | `a`: 要排序的数组。 |
| `static int binarySearch(int[] a, int key)` | 在**有序**数组中进行二分查找。 | `a`: 有序数组。<br>`key`: 要查找的元素。<br>返回：找到则返回索引，否则返回负数。 |
| `static int[] copyOf(int[] original, int newLength)` | 复制数组，生成一个指定长度的新数组。 | `original`: 原数组。<br>`newLength`: 新数组的长度。 |
| `static boolean equals(int[] a1, int[] a2)` | 比较两个数组的长度和元素是否完全相同。 | `a1`, `a2`: 要比较的两个数组。 |
| `static void fill(int[] a, int val)` | 用指定的值填充数组的所有元素。 | `a`: 要填充的数组。<br>`val`: 填充值。 |

## 5. 数组的常见异常

### 5.1. 数组索引越界异常 (ArrayIndexOutOfBoundsException)

当访问数组时，使用的索引超出了 `[0, 数组长度 - 1]` 的范围。

```java
int[] arr = {1, 2, 3};
// System.out.println(arr[3]); // 错误，索引3越界，将抛出异常
System.out.println(arr[arr.length - 1]); // 正确，访问最后一个元素
```

### 5.2. 空指针异常 (NullPointerException)

当一个数组引用为 `null` 时，尝试访问其元素或属性（如 `length`）会引发此异常。

```java
// 情况一：数组引用为 null
int[] arr1 = null;
// System.out.println(arr1.length); // 抛出 NullPointerException

// 情况二：二维数组的内部一维数组为 null
int[][] arr2 = new int[3][];
// System.out.println(arr2[0][0]); // arr2[0] 为 null，抛出 NullPointerException
```
