## 1. Swing 概述

图形用户界面（GUI）为程序提供了图形化的交互方式。Java 早期的 AWT（抽象窗口工具箱）旨在构建通用 GUI，但未能完全满足跨平台一致性的需求。为此，Swing 应运而生。Swing 是 AWT 的增强组件，提供了更丰富、功能更强大的 GUI 构建块。Swing 组件可以与 AWT 组件共存。

### 1.1 Swing 的特点

-   **轻量级组件**：Swing 组件几乎完全由 Java 语言编写，不依赖于本地操作系统的原生 GUI 组件。这使得 Swing 组件在不同平台上的行为和外观更加一致。相比之下，AWT 组件是“重量级组件”，依赖于本地平台的窗口系统。
-   **可插入外观（Pluggable Look and Feel - PLAF）**：Swing 允许开发者在运行时改变应用程序的外观和风格，可以模拟特定操作系统（如 Windows、Motif）的观感，或者使用 Java 自带的跨平台观感（如 Metal、Nimbus）。
-   **更丰富的组件集**：Swing 提供了比 AWT 更多的组件类型，例如表格、树、文本编辑器等。

### 1.2 Swing 包层级

Swing 的核心类位于 `javax.swing` 包中。理解其类层次结构对于有效使用 Swing 至关重要：

-   **`java.awt.Component`**：AWT 组件的基类，定义了所有 GUI 组件的基本属性和行为，如大小、位置、可见性、事件处理等。
-   **`java.awt.Container`**：`Component` 的子类，能够容纳其他组件，并管理它们的布局。
    -   **`java.awt.Window`**：表示一个没有边框和标题栏的顶层窗口。`JFrame` 和 `JDialog` 间接从此类派生。
    -   **`java.awt.Frame`**：`Window` 的子类，表示一个具有标题栏、边框和标准窗口操作（最小化、最大化、关闭）的顶层窗口。`JFrame` 直接从此类派生。
-   **`javax.swing.JComponent`**：Swing 组件的基类，继承自 `java.awt.Container`。它为所有具体的 Swing 组件（如 `JButton`、`JLabel` 等）提供了共同的特性，包括边框设置、工具提示、可插入外观等。

Swing 组件的容器通常是 `JFrame`、`JDialog` 或 `JPanel`。组件被添加到容器中，容器负责管理其子组件的布局和显示。

## 2. 常见顶层窗体

窗体是 Swing 应用程序中承载其他组件的顶层容器。

### 2.1 JFrame 窗体

`JFrame` 是一个顶层窗口，通常作为应用程序的主窗口。它可以包含菜单栏、内容面板以及其他组件。

**核心用法**：
1.  创建 `JFrame` 对象。
2.  通过 `getContentPane()` 获取其内容面板（一个 `Container` 对象）。
3.  向内容面板中添加组件。
4.  设置窗口大小、关闭操作和可见性。

**示例代码**：
```java
import javax.swing.*;
import java.awt.*;

public class MyFrameExample {
    public static void main(String[] args) {
        // 在事件调度线程中创建和显示 GUI
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("JFrame 示例"); // 设置标题
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); // 设置关闭操作
            frame.setSize(400, 300); // 设置大小

            // 获取内容面板并添加组件
            Container contentPane = frame.getContentPane();
            contentPane.setLayout(new FlowLayout()); // 设置布局管理器
            JLabel label = new JLabel("这是一个 JFrame 窗体");
            JButton button = new JButton("点击我");
            contentPane.add(label);
            contentPane.add(button);

            // frame.pack(); // 或者使用 pack() 根据内容自动调整大小
            frame.setLocationRelativeTo(null); // 窗口居中显示
            frame.setVisible(true); // 使窗体可见
        });
    }
}
```

**常用构造方法**：

| 方法签名             | 功能描述                                     |
| -------------------- | -------------------------------------------- |
| `JFrame()`           | 创建一个初始不可见、没有标题的新 `JFrame`。    |
| `JFrame(String title)` | 创建一个初始不可见、但具有指定标题的 `JFrame`。 |

**常用方法**：

| 方法签名                                  | 功能描述                                                     | 参数说明                                                                                               | 可选性 |
| ----------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | ------ |
| `Container getContentPane()`             | 获取此框架的内容面板容器，组件应添加到此面板。               | 无                                                                                                     | -      |
| `void setDefaultCloseOperation(int operation)` | 设置用户在此窗体上发起“关闭”时默认发生的操作。             | `operation`：关闭操作常量，如 `JFrame.EXIT_ON_CLOSE`（退出程序）、`JFrame.DISPOSE_ON_CLOSE`（销毁窗口）、`JFrame.HIDE_ON_CLOSE`（隐藏窗口）、`JFrame.DO_NOTHING_ON_CLOSE`（无操作） | -      |
| `void setSize(int width, int height)`     | 设置窗体的宽度和高度。                                       | `width`：宽度（像素），`height`：高度（像素）                                                            | -      |
| `void setBounds(int x, int y, int width, int height)` | 设置窗体的位置和大小。                                       | `x`、`y`：左上角坐标；`width`、`height`：宽高                                                          | -      |
| `void setVisible(boolean b)`              | 显示或隐藏此组件，具体取决于参数 `b` 的值。                  | `b`：`true` 表示显示，`false` 表示隐藏                                                                   | -      |
| `void setTitle(String title)`             | 设置窗体的标题。                                             | `title`：窗体标题                                                                                        | -      |

| `void setLayout(LayoutManager mgr)`       | 设置此容器（通常是内容面板）的布局管理器。                   | `mgr`：布局管理器对象                                                                                    | -      |
| `void pack()`                             | 调整此窗口的大小，以适合其子组件的首选大小和布局。             | 无                                                                                                     | -      |
| `void setLocationRelativeTo(Component c)` | 设置窗口相对于指定组件的位置。如果组件为 `null`，则窗口将置于屏幕的中央。 | `c`：窗口将相对于其定位的组件                                                                        | 可选   |

**窗体关闭方式常量**（位于 `WindowConstants` 接口，`JFrame` 已实现）：

| 关闭窗体方式          | 描述                                     |
| --------------------- | ---------------------------------------- |
| `EXIT_ON_CLOSE`       | 退出应用程序（默认的 `JFrame` 关闭操作通常不是这个，需要显式设置）。 |
| `DO_NOTHING_ON_CLOSE` | 不执行任何操作，程序需自己处理关闭事件。   |
| `HIDE_ON_CLOSE`       | 隐藏窗口（窗口对象仍然存在，可以再次显示）。  |
| `DISPOSE_ON_CLOSE`    | 销毁窗口（释放窗口占用的资源）。            |

### 2.2 JDialog 窗体

`JDialog` 用于创建对话框窗口，通常用于显示临时信息、警告或从用户获取输入。对话框可以是模态的（阻塞父窗口）或非模态的。

**核心用法**：
1.  创建 `JDialog` 对象，通常指定其父窗体（`Frame` 或 `Dialog`）和模态性。
2.  与 `JFrame` 类似，通过 `getContentPane()` 获取内容面板并添加组件。
3.  设置对话框大小、关闭操作和可见性。

**示例代码**：
```java
import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class MyDialogExample {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("主窗口");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            frame.setSize(300, 200);
            frame.setLayout(new FlowLayout());

            JButton openDialogButton = new JButton("打开对话框");
            openDialogButton.addActionListener(e -> {
                // 创建 JDialog 对象
                // 参数: 父窗体, 标题, 是否模态
                JDialog dialog = new JDialog(frame, "我的对话框", true); // true 表示模态
                dialog.setSize(250, 150);
                dialog.setLayout(new FlowLayout());
                dialog.add(new JLabel("这是一个模态对话框。"));
                JButton closeButton = new JButton("关闭");
                closeButton.addActionListener(ev -> dialog.dispose()); // dispose() 关闭对话框并释放资源
                dialog.add(closeButton);
                
                dialog.setLocationRelativeTo(frame); // 相对于父窗体居中
                dialog.setVisible(true); // 显示对话框，模态对话框会在此阻塞
            });

            frame.add(openDialogButton);
            frame.setLocationRelativeTo(null);
            frame.setVisible(true);
        });
    }
}
```

**常用构造方法**：

| 构造方法                                            | 功能描述                                                                 |
| --------------------------------------------------- | ------------------------------------------------------------------------ |
| `JDialog()`                                         | 创建一个无标题、无父窗体、非模态的对话框。                               |
| `JDialog(Frame owner)`                              | 创建一个无标题、指定父窗体、非模态的对话框。                               |
| `JDialog(Frame owner, boolean modal)`               | 创建一个无标题、指定父窗体、指定模态性的对话框。                           |
| `JDialog(Frame owner, String title)`                | 创建一个指定标题、指定父窗体、非模态的对话框。                             |
| `JDialog(Frame owner, String title, boolean modal)` | 创建一个指定标题、指定父窗体、指定模态性的对话框。                         |
| `JDialog(Dialog owner, String title, boolean modal)`| 类似地，父组件也可以是另一个 `Dialog`。                                  |

**模态性（Modality）**：
-   **模态（Modal）**：当模态对话框显示时，它会阻塞其父窗口以及应用程序中其他顶层窗口的用户输入，直到该对话框被关闭。用于需要用户立即响应的情况。
-   **非模态（Modeless）**：非模态对话框显示时，用户仍然可以与其父窗口和其他窗口交互。

`JDialog` 的其他常用方法如 `getContentPane()`、`setSize()`、`setVisible()`、`setDefaultCloseOperation()` 等与 `JFrame` 类似。通常对话框使用 `DISPOSE_ON_CLOSE` 作为关闭操作。

### 3.2 按钮组件

Swing 中的按钮是较为常见的组件，它用于触发特定动作。

#### 3.2.1 普通按钮：JButton

`JButton` 用于创建一个带标签的按钮，用户点击它可以触发一个动作。按钮上可以显示文本、图标或两者。

**核心用法**：
创建 `JButton`，然后使用 `addActionListener()` 为其添加事件监听器以响应点击。

**示例代码**：
```java
// 在 JFrame 或 JPanel 的构造方法或初始化块中
JButton textButton = new JButton("点我");
// ImageIcon icon = new ImageIcon("path/to/icon.png");
// JButton iconButton = new JButton(icon);
// JButton combinedButton = new JButton("保存", icon);

textButton.addActionListener(e -> {
    System.out.println("按钮 '" + e.getActionCommand() + "' 被点击了!");
    // e.getActionCommand() 默认返回按钮的文本
});

// panel.add(textButton);
```

**常用构造方法**：

| 构造方法                        | 功能描述                                 |
| ------------------------------- | ---------------------------------------- |
| `JButton()`                     | 创建一个无文本、无图标的按钮。           |
| `JButton(String text)`          | 创建一个带指定文本的按钮。               |
| `JButton(Icon icon)`            | 创建一个带指定图标的按钮。               |
| `JButton(String text, Icon icon)` | 创建一个既有文本又有图标的按钮。         |

#### 3.2.2 单选按钮：JRadioButton

`JRadioButton` 允许用户从一组选项中选择一个。为了实现互斥选择（即一组中只能选一个），必须将多个 `JRadioButton` 添加到一个 `ButtonGroup` 对象中。

**核心用法**：
1.  创建多个 `JRadioButton` 对象。
2.  创建一个 `ButtonGroup` 对象。
3.  将每个 `JRadioButton` 添加到 `ButtonGroup` 中。
4.  可以为单选按钮添加 `ActionListener` 或 `ItemListener` 来响应状态改变。

**示例代码**：
```java
// 在 JFrame 或 JPanel 的构造方法或初始化块中
JRadioButton option1 = new JRadioButton("选项 A");
JRadioButton option2 = new JRadioButton("选项 B", true); // true 表示默认选中
JRadioButton option3 = new JRadioButton("选项 C");

ButtonGroup group = new ButtonGroup();
group.add(option1);
group.add(option2);
group.add(option3);

ActionListener listener = e -> {
    JRadioButton source = (JRadioButton) e.getSource();
    if (source.isSelected()) {
        System.out.println(source.getText() + " 被选中");
    }
};
option1.addActionListener(listener);
option2.addActionListener(listener);
option3.addActionListener(listener);

// panel.add(option1);
// panel.add(option2);
// panel.add(option3);
```

**常用构造方法**：

| 构造方法                                     | 功能描述                                                     |
| -------------------------------------------- | ------------------------------------------------------------ |
| `JRadioButton()`                             | 创建一个未选中的、无文本的单选按钮。                           |
| `JRadioButton(String text)`                  | 创建一个未选中的、带指定文本的单选按钮。                       |
| `JRadioButton(String text, boolean selected)`| 创建一个带指定文本和指定选择状态的单选按钮。                   |
| `JRadioButton(Icon icon)`                    | 创建一个未选中的、带指定图标的单选按钮。                       |
| `JRadioButton(Icon icon, boolean selected)`  | 创建一个带指定图标和指定选择状态的单选按钮。                   |
| `JRadioButton(String text, Icon icon)`       | 创建一个未选中的、带指定文本和图标的单选按钮。                 |
| `JRadioButton(String text, Icon icon, boolean selected)` | 创建一个带指定文本、图标和选择状态的单选按钮。             |

**ButtonGroup 常用方法**：

| 方法签名                          | 功能描述                                 | 参数说明                     | 可选性 |
| --------------------------------- | ---------------------------------------- | ---------------------------- | ------ |
| `void add(AbstractButton button)` | 将按钮添加到组中。                       | `button`：要添加的单选按钮等 | -      |
| `void remove(AbstractButton button)`| 从组中移除按钮。                         | `button`：要移除的按钮       | -      |

#### 3.3.2 密码框：JPasswordField

    char[] password = passwordField.getPassword();
    // 处理密码 (例如: new String(password))
    // 使用后应尽快清除 char[]: java.util.Arrays.fill(password, ' ');
    System.out.println("输入的密码字符数: " + password.length);

// panel.add(passwordField);
// panel.add(loginButton);

### 3.4 列表组件

#### 3.4.1 下拉列表框：JComboBox<E>

JComboBox<String> comboBox = new JComboBox<>(items);

comboBox.addActionListener(e -> {
    String selectedItem = (String) comboBox.getSelectedItem();
    int selectedIndex = comboBox.getSelectedIndex();
    if (selectedIndex > 0) { // 假设第一项是提示项
        System.out.println("选中项: " + selectedItem + ", 索引: " + selectedIndex);
    }
});

// panel.add(comboBox);

#### 3.4.2 列表框：JList<E>

`JList`（泛型 `<E>` 表示列表项的类型）用于显示一个项目列表，允许用户选择一项或多项。与 `JComboBox` 不同，`JList` 通常直接显示其所有或部分项目。如果项目过多，应将其放入 `JScrollPane`。

**核心用法**：
1.  创建 `JList`，通常使用一个数组、`Vector` 或 `ListModel`（如 `DefaultListModel`）初始化其列表项。
2.  将其放入 `JScrollPane`。
3.  通过 `addListSelectionListener()` 监听选项变化。
4.  通过 `getSelectedValue()` 或 `getSelectedValuesList()` 获取选中项。

**示例代码**：
```java
// 在 JFrame 或 JPanel 的构造方法或初始化块中
DefaultListModel<String> listModel = new DefaultListModel<>();
listModel.addElement("条目 1");
listModel.addElement("条目 2");
listModel.addElement("条目 3");
listModel.addElement("条目 4");

JList<String> list = new JList<>(listModel);
// ListSelectionModel.SINGLE_SELECTION, SINGLE_INTERVAL_SELECTION, MULTIPLE_INTERVAL_SELECTION
list.setSelectionMode(ListSelectionModel.SINGLE_SELECTION); 

list.addListSelectionListener(e -> {
    if (!e.getValueIsAdjusting()) { // 避免处理中间选择事件
        String selectedValue = list.getSelectedValue();
        if (selectedValue != null) {
            System.out.println("选中: " + selectedValue);
        }
    }
});

JScrollPane listScrollPane = new JScrollPane(list);
// panel.add(listScrollPane);
```
