## 1. 记录 (Record)

### 1.1. 什么是记录？

在 Java 16 中正式引入的**记录 (`record`)** 是一种特殊类型的类，其主要目标是作为**不可变数据的透明载体**。

通俗地说，记录是为那些只为了“携带”数据而存在的类（通常称为 POJO 或数据类）提供的一种紧凑语法。

### 1.2. 为什么使用记录？

在记录出现之前，如果我们需要创建一个简单的 `Person` 类来存储姓名和年龄，通常需要编写大量样板代码：

**传统方式（样板代码）:**

```java
public final class PersonTraditional {
    private final String name;
    private final int age;

    public PersonTraditional(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    @Override
    public boolean equals(Object obj) {
        // ... equals() 的实现
    }

    @Override
    public int hashCode() {
        // ... hashCode() 的实现
    }

    @Override
    public String toString() {
        // ... toString() 的实现
    }
}
```
这样的代码非常冗长，而其核心目的仅仅是存储 `name` 和 `age`。

**记录方式（简洁语法）:**
使用 `record` 关键字，我们可以将上面的所有代码简化为一行：

```java
public record Person(String name, int age) {}
```
这行代码包含了与传统方式完全相同的功能。编译器会自动为我们生成：
*   所有组件对应的 `private final` 字段。
*   一个包含了所有组件的**公共构造器**。
*   每个组件对应的 `public` **访问器方法**（例如 `name()` 和 `age()`，注意没有 `get` 前缀）。
*   恰当实现的 `equals()`、`hashCode()` 和 `toString()` 方法。

## 2. 记录的定义与使用

### 2.1. 基本定义

使用 `record` 关键字，并在括号中声明其所有的数据组件。

```java
// 定义一个表示二维坐标点的记录
public record Point(int x, int y) {
    // 类体通常是空的
}
```
*   `Point` 是记录的名称。
*   `int x` 和 `int y` 是记录的**组件 (components)**，它们定义了记录所包含的数据。

### 2.2. 基本使用

记录的实例化和使用与普通类相似。

```java
public class TestPoint {
    public static void main(String[] args) {
        // 1. 实例化记录
        Point p1 = new Point(10, 20);
        Point p2 = new Point(10, 20);

        // 2. 使用访问器方法获取数据
        System.out.println("p1 的 x 坐标是: " + p1.x()); // 输出 10
        System.out.println("p1 的 y 坐标是: " + p1.y()); // 输出 20

        // 3. 自动生成的 toString() 方法
        System.out.println("p1 的字符串表示: " + p1); // 输出: Point[x=10, y=20]

        // 4. 自动生成的 equals() 方法
        System.out.println("p1 和 p2 是否相等: " + p1.equals(p2)); // 输出: true

        // 5. 自动生成的 hashCode() 方法
        System.out.println("p1 的哈希码: " + p1.hashCode());
    }
}
```

## 3. 记录的构造器

虽然编译器会为我们生成一个默认的公共构造器，但我们也可以自定义构造器以满足特殊需求，例如数据校验。

### 3.1. 紧凑构造器 (Compact Constructor)

紧凑构造器是记录独有的一种特殊构造器，它没有参数列表 `()`。它的主要用途是在将参数赋值给字段**之前**，对数据进行校验或规范化。

```java
public record Range(int start, int end) {
    // 紧凑构造器，用于数据校验
    public Range {
        if (start > end) {
            throw new IllegalArgumentException("起始值不能大于结束值");
        }
    }
}

public class TestRange {
    public static void main(String[] args) {
        Range r1 = new Range(1, 10); // 正常创建
        System.out.println(r1);

        try {
            Range r2 = new Range(20, 10); // 将会抛出异常
        } catch (IllegalArgumentException e) {
            System.out.println("创建失败: " + e.getMessage());
        }
    }
}
```
> **注意**：在紧凑构造器中，你**不需要**写 `this.start = start;` 这样的赋值语句，编译器会在你的代码执行完毕后自动完成赋值。

### 3.2. 自定义规范构造器 (Custom Canonical Constructor)

你也可以重写与所有组件匹配的**规范构造器**。这提供了完全的控制权，但同时也意味着你必须自己负责所有字段的赋值。

```java
public record Person(String name, int age) {
    // 自定义规范构造器
    public Person(String name, int age) {
        // 可以在这里添加逻辑，例如将 name 转换为大写
        this.name = name.toUpperCase();
        this.age = age;
    }
}
```

### 3.3. 自定义非规范构造器 (Custom Non-Canonical Constructor)

记录还可以有其他非规范构造器，但它们**必须**通过 `this()` 最终调用规范构造器。

```java
public record Person(String name, int age) {
    // 自定义一个只接收 name 的构造器，age 默认为 0
    public Person(String name) {
        this(name, 0); // 必须调用本类其他的构造器
    }
}
```

## 4. 记录的其他特性

*   **不可变性**：记录的字段是隐式的 `final`，一旦创建，其状态就不能被修改。
*   **可以实现接口**：`public record Point(int x, int y) implements Serializable { ... }`
*   **可以有静态成员**：可以定义静态字段、静态方法。
*   **不能继承其他类**：所有记录都隐式地继承自 `java.lang.Record`，因此不能再继承其他类。
*   **不能被继承**：记录是隐式的 `final`，不能作为其他类的父类。
