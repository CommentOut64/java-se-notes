## 1. 包 (Package)

包（`package`）是 Java 中组织代码的一种机制，类似于电脑中用来管理文件的**文件夹**。它将功能相近或相关的类和接口组织在一起。

使用包主要有两个目的：
1.  **便于管理**：将大量的类分门别类，使项目结构更清晰。
2.  **避免命名冲突**：不同的包中可以有同名的类。例如，`com.company.a.Util` 和 `com.company.b.Util` 是两个不同的类。

包的命名规范通常是公司或组织域名的倒序，例如 `com.google.common`。

## 2. 在包中创建类

要将一个类放入指定的包中，只需在 Java 源文件的**第一行**使用 `package` 关键字声明其所在的包。

**语法：**

```java
package com.example.model; // 声明该类属于 com.example.model 包

public class Person {
    // 类的代码...
}
```
*   `package` 语句必须是源文件中的**第一条非注释性代码**。
*   一个源文件最多只能有一个 `package` 语句。

## 3. 类的导入 (import)

如果想在一个类中使用另一个不同包中的类，就需要先将其“导入”。

如果不导入，就必须使用类的全限定名（如 `java.util.Scanner`），这会非常繁琐。

### 3.1. 导入单个类

**语法：**

```java
import java.util.Scanner; // 只导入 Scanner 这一个类

public class App {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in); // 可以直接使用类名
    }
}
```

### 3.2. 导入整个包中的类

使用通配符 `*` 可以导入指定包下的所有**公共（public）**类。

**语法：**
```java
import java.util.*; // 导入 java.util 包下的所有公共类

public class App {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random random = new Random();
    }
}
```
> **注意**：
> *   `import java.util.*;` 不会导入 `java.util` 的子包（如 `java.util.concurrent`）中的类。
> *   `java.lang` 包是 Java 的核心包（包含 `String`、`System`、`Math` 等），它会被自动导入到每一个 Java 文件中，无需手动 `import`。

## 4. 静态导入 (import static)

静态导入允许你导入一个类中的**静态成员（静态字段和静态方法）**，从而在代码中可以直接使用这些成员，而无需通过 `类名.` 的方式来调用。

**未使用静态导入：**
```java
public class Calculator {
    public static void main(String[] args) {
        // 每次都要写 Math.
        double r = Math.sqrt(Math.pow(3, 2) + Math.pow(4, 2));
        System.out.println("圆周率是: " + Math.PI);
    }
}
```

**使用静态导入后：**
```java
import static java.lang.Math.sqrt;  // 只导入 sqrt 方法
import static java.lang.Math.pow;   // 只导入 pow 方法
import static java.lang.Math.PI;    // 只导入 PI 静态字段

// 也可以使用通配符导入所有静态成员：import static java.lang.Math.*;

public class Calculator {
    public static void main(String[] args) {
        // 可以直接使用静态成员
        double r = sqrt(pow(3, 2) + pow(4, 2));
        System.out.println("圆周率是: " + PI);
    }
}
```
> **注意**：过度使用静态导入可能会降低代码的可读性，因为读者可能不清楚某个静态方法或字段来自哪个类。请谨慎使用。

## 5. 包访问权限 (Default Access)

在 Java 中，如果没有为类、方法或成员变量指定任何访问修饰符（`public`, `protected`, `private`），那么它就拥有**包访问权限**（也称为默认权限）。

这意味着，该成员**只能被同一个包中的其他类访问**。

**示例：**

`com/example/tools/Tool.java` 文件：

```java
package com.example.tools;

public class Tool {
    // 这个方法没有访问修饰符，是包访问权限
    void performAction() {
        System.out.println("执行一个包内可见的操作。");
    }
}
```

`com/example/tools/App.java` 文件 (与 `Tool` 在同一个包)：
```java
package com.example.tools;

public class App {
    public static void main(String[] args) {
        Tool tool = new Tool();
        tool.performAction(); // 正确：可以访问，因为在同一个包中
    }
}
```

`com/example/main/MainApp.java` 文件 (在不同的包中)：
```java
package com.example.main;

import com.example.tools.Tool;

public class MainApp {
    public static void main(String[] args) {
        Tool tool = new Tool();
        // tool.performAction(); // 编译错误！无法访问，因为不在同一个包中
    }
}
```

## 6. 类路径 (Classpath)

类路径（Classpath）是告诉 Java 编译器（`javac`）和 Java 虚拟机（`java`）**去哪里查找所需的 `.class` 文件**的一个路径列表。

*   当你编译或运行 Java 程序时，JVM 需要根据类的全限定名（如 `com.example.model.Person`）来定位对应的字节码文件 (`Person.class`)。
*   JVM 会在类路径指定的目录和 JAR 文件中，寻找一个与包名匹配的文件夹结构，即 `com/example/model/Person.class`。

对于新手而言，你**几乎不需要手动设置类路径**，因为：
*   **IDE（如 IntelliJ IDEA, Eclipse）** 会自动管理项目的类路径。
*   **构建工具（如 Maven, Gradle）** 也会自动处理所有依赖和类路径问题。
