## 1. 枚举类 (Enum)

### 1.1. 什么是枚举类？

枚举(`enum`)是一种特殊的类，它用于表示一组固定的常量。

使用枚举可以增强代码的**可读性**和**类型安全**。

### 1.2. 为什么使用枚举？

在枚举出现之前，开发者通常使用静态常量(`static final`)来表示一组固定的值：
```java
public static final int SEASON_SPRING = 1;
public static final int SEASON_SUMMER = 2;
```
这种方式存在一些问题：
*   **类型不安全**：你可以传递任何 `int` 值给一个期望接收季节参数的方法，编译器无法检查其有效性。
*   **可读性差**：打印出的值(如 `1`)没有实际意义，需要开发者去查找其代表的含义。

枚举类完美地解决了这些问题。

## 2. 枚举的定义与使用

### 2.1. 基本定义

使用 `enum` 关键字定义一个枚举类。

```java
// 定义一个表示季节的枚举类
public enum Season {
    SPRING,
    SUMMER,
    AUTUMN,
    WINTER
}
```
*   **枚举常量**：`SPRING`, `SUMMER`, `AUTUMN`, `WINTER` 是该枚举类的四个实例，它们通常用大写字母表示。
*   **隐式修饰**：这些常量默认被 `public static final` 修饰。

### 2.2. 基本使用

可以像访问静态字段一样使用枚举常量，并将其用于 `switch` 语句中。

```java
public class TestSeason {
    public static void main(String[] args) {
        // 1. 声明和赋值
        Season currentSeason = Season.AUTUMN;

        // 2. 在 switch 语句中使用
        switch (currentSeason) {
            case SPRING:
                System.out.println("春天到了，万物复苏。");
                break;
            case SUMMER:
                System.out.println("夏天来了，骄阳似火。");
                break;
            case AUTUMN:
                System.out.println("秋天到了，天高气爽。");
                break;
            case WINTER:
                System.out.println("冬天来了，白雪皑皑。");
                break;
        }
    }
}
```
> **注意**：在 `switch` 的 `case` 语句中，直接使用常量名(如 `SPRING`)，而不能写成 `Season.SPRING`。

## 3. 向枚举中添加成员

Java 的枚举远不止是常量集合，它本质上是一个特殊的类，因此可以拥有自己的**成员变量**、**方法**和**构造器**。

### 3.1. 添加构造器和成员变量

如果你希望每个枚举常量都关联一些额外信息，可以为其添加成员变量和构造器。

*   枚举类的构造器必须是 `private`(私有的)，这是为了确保外部代码不能创建新的实例。
*   定义常量时，需要通过 `()` 调用相应的构造器。

```java
public enum Season {
    // 定义常量时，调用私有构造器
    SPRING("春天", "温暖"),
    SUMMER("夏天", "炎热"),
    AUTUMN("秋天", "凉爽"),
    WINTER("冬天", "寒冷");

    private final String chineseName; // 中文名
    private final String description; // 描述

    // 构造器必须是 private
    private Season(String chineseName, String description) {
        this.chineseName = chineseName;
        this.description = description;
    }

    // 提供 public 方法供外部访问
    public String getChineseName() {
        return chineseName;
    }

    public String getDescription() {
        return description;
    }
}
```

### 3.2. 使用带成员的枚举

```java
public class TestSeasonAdvanced {
    public static void main(String[] args) {
        Season summer = Season.SUMMER;
        
        System.out.println("英文名: " + summer.name()); // summer
        System.out.println("中文名: " + summer.getChineseName()); // 夏天
        System.out.println("季节描述: " + summer.getDescription()); // 炎热
    }
}
```

## 4. 枚举类的常用方法

所有枚举类都隐式地继承自 `java.lang.Enum` 类，因此它们都拥有一些内置的常用方法。

| 方法签名                        | 功能描述                                                     | 示例                                           |
| :------------------------------ | :----------------------------------------------------------- | :--------------------------------------------- |
| `static T[] values()`           | **静态方法**，返回一个包含所有枚举常量的数组。常用于遍历。   | `Season[] allSeasons = Season.values();`       |
| `static T valueOf(String name)` | **静态方法**，根据给定的字符串名称，返回对应的枚举常量。     | `Season s = Season.valueOf("WINTER");`         |
| `String name()`                 | 返回枚举常量的名称(即定义时的字符串，如 "SPRING")。          | `String n = Season.SPRING.name();`             |
| `int ordinal()`                 | 返回枚举常量在定义时的序数(从 0 开始)。                      | `int index = Season.SPRING.ordinal();`         |
| `String toString()`             | 默认返回与 `name()` 相同的结果，可以被重写以提供更友好的输出。 | `System.out.println(Season.SPRING); // SPRING` |

**遍历枚举示例：**
```java
// 使用 values() 方法遍历所有季节
for (Season s : Season.values()) {
    System.out.println(s.getChineseName() + "的序数是: " + s.ordinal());
}
```
> **注意**：开发中应尽量避免使用 `ordinal()` 方法来做业务逻辑判断，因为它与常量的声明顺序紧密相关，一旦顺序改变，逻辑就会出错。

## 5. 实现接口

枚举类也可以像普通类一样实现接口，这使得枚举的功能更加强大和灵活。

```java
interface Displayable {
    void display();
}

public enum Color implements Displayable {
    RED, GREEN, BLUE;

    @Override
    public void display() {
        System.out.println("当前颜色是: " + this.name());
    }
}

public class TestColor {
    public static void main(String[] args) {
        Color.RED.display(); // 输出: 当前颜色是: RED
        Displayable blue = Color.BLUE;
        blue.display();      // 输出: 当前颜色是: BLUE
    }
}
```
