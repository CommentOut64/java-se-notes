| 修饰符    | 本类 | 本包                      | 其他包子类                  | 其他包非子类 |
| --------- | ---- | ------------------------- | --------------------------- | ------------ |
| private   | ✓    | ✗                         | ✗                           | ✗            |
| 缺省      | ✓    | ✓（本包子类非子类都可见） | ✗                           | ✗            |
| protected | ✓    | ✓（本包子类非子类都可见） | ✓（其他包仅限于子类中可见） | ✗            |
| public    | ✓    | ✓                         | ✓                           | ✓            |

- 外部类：public和缺省

- 成员变量、成员方法等：public,protected,缺省,private

- `private` 方法不属于类的可见成员，即使子类定义了同名方法，也只是“新方法”，并非重写（override）。这样可以确保某些关键逻辑不会被子类意外覆盖。
