## 1. Collection 子接口一：List

### 1.1 List 接口特点

`java.util.List` 接口是 `Collection` 接口的一个重要子接口，它代表一个**有序的元素序列**。与数组相比，`List` 提供了更灵活的数据存储和操作方式。

*   **有序性 (Ordered)**：`List` 中的元素按照插入顺序进行存储，每个元素都有其对应的索引，第一个元素的索引是 0。
*   **可重复性 (Repeatable)**：`List` 允许存储重复的元素，即同一个对象可以多次出现在 `List` 中。

JDK API 中 `List` 接口的常用实现类有 `ArrayList`、`LinkedList` 和 `Vector`。

### 1.2 List 接口方法

`List` 接口继承了 `Collection` 接口的所有方法，并额外定义了一些基于索引操作元素的方法。

| 方法签名                                               | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `void add(int index, E element)`                       | 在列表的指定位置 `index` 插入指定的元素 `element`。          | `index`：要插入元素的索引位置<br>`element`：要插入的元素     |
| `boolean addAll(int index, Collection<? extends E> c)` | 将指定集合 `c` 中的所有元素从指定位置 `index` 开始插入到此列表中。 | `index`：开始插入指定集合中元素的索引位置<br>`c`：包含要添加到此列表的元素的集合 |
| **`E get(int index)`**                                 | 返回列表中指定位置 `index` 的元素。                          | `index`：要返回元素的索引                                    |
| `List<E> subList(int fromIndex, int toIndex)`          | 返回列表中指定的 `fromIndex` (包含)到 `toIndex` (不包含)部分的一个视图。 | `fromIndex`：子列表的起始索引(包含)<br>`toIndex`：子列表的结束索引(不包含) |
| `int indexOf(Object o)`                                | 返回指定元素 `o` 在此列表中首次出现的索引，如果列表不包含此元素，则返回 -1。 | `o`：要搜索的元素                                            |
| `int lastIndexOf(Object o)`                            | 返回指定元素 `o` 在此列表中最后一次出现的索引，如果列表不包含此元素，则返回 -1。 | `o`：要搜索的元素                                            |
| `E remove(int index)`                                  | 移除列表中指定位置 `index` 的元素，并返回被移除的元素。      | `index`：要移除元素的索引                                    |
| `E set(int index, E element)`                          | 用指定的元素 `element` 替换列表中指定位置 `index` 的元素，并返回被替换的元素。 | `index`：要替换元素的索引<br>`element`：要存储在指定位置的新元素 |

**代码示例**：

```java
import java.util.ArrayList;
import java.util.List;

public class TestListMethod {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();

        // 添加元素
        list.add("Apple");
        list.add("Banana");
        list.add("Cherry");
        System.out.println(list); // 输出: [Apple, Banana, Cherry]

        // 在指定位置添加元素
        list.add(1, "Orange"); // 在索引1处插入Orange
        System.out.println(list); // 输出: [Apple, Orange, Banana, Cherry]

        // 获取元素
        String fruit = list.get(2);
        System.out.println("Index 2 is: " + fruit); // 输出: Index 2 is: Banana

        // 删除元素
        String removedFruit = list.remove(0); // 删除索引0处的元素
        System.out.println("Removed: " + removedFruit); // 输出: Removed: Apple
        System.out.println(list); // 输出: [Orange, Banana, Cherry]

        // 替换元素
        list.set(1, "Grape"); // 将索引1处的元素替换为Grape
        System.out.println(list); // 输出: [Orange, Grape, Cherry]

        // 遍历
        for (String s : list) {
            System.out.println(s);
        }
    }
}
```
> 注意：导入 `List` 时，请确保导入的是 `java.util.List`，而非 `java.awt.List` (后者是图形界面组件)。

## 2. List 接口的主要实现类

### 2.1 ArrayList

*   `ArrayList` 是 `List` 接口最常用的实现类，其底层是基于**`动态数组`**实现的。
*   **特点**：
    *   **查询效率高**：由于元素在内存中是连续存储的，通过索引访问元素 (调用 `get` 方法) 非常快，时间复杂度为 O(1)。
    *   **增删效率相对较低**：在列表中间插入或删除元素时，可能需要移动后续元素，时间复杂度为 O(n)。但在列表末尾添加或删除元素通常较快 (摊销时间复杂度为 O(1))。
    *   **线程不安全**。
*   **`Arrays.asList(...)` 返回的 `List`**：
    *   `java.util.Arrays.asList(...)` 方法返回的 `List` 并非 `java.util.ArrayList` 的实例，而是 `Arrays` 类的一个私有静态内部类 `ArrayList` 的实例。
    *   这个返回的 `List` **长度是固定的**，不支持 `add()`、`remove()` 等会改变集合大小的操作，尝试这些操作会抛出 `UnsupportedOperationException`。但可以使用 `set()` 方法修改元素。

### 2.2 LinkedList

*   `LinkedList` 是 `List` 接口的另一个常用实现类，其底层是基于**`双向链表`**实现的。它也实现了 `Deque` 接口，因此具备双端队列的功能。
*   **特点**：
    *   **增删效率高**：在链表中插入或删除元素时，只需修改相邻节点的指针，时间复杂度接近 O(1) (不考虑查找元素位置的时间)。
    *   **查询效率相对较低**：访问链表中的元素需要从头或尾开始遍历，时间复杂度为 O(n)。
    *   **线程不安全**。
*   **常用特有方法 (源自 `Deque` 接口)**：

    | 方法签名             | 功能描述                         | 参数说明                    |
    | :------------------- | :------------------------------- | :-------------------------- |
    | `void addFirst(E e)` | 在列表开头插入指定元素 `e`。     | `e`：要添加到列表开头的元素 |
    | `void addLast(E e)`  | 在列表末尾追加指定元素 `e`。     | `e`：要追加到列表末尾的元素 |
    | `E getFirst()`       | 返回此列表的第一个元素。         | -                           |
    | `E getLast()`        | 返回此列表的最后一个元素。       | -                           |
    | `E removeFirst()`    | 移除并返回此列表的第一个元素。   | -                           |
    | `E removeLast()`     | 移除并返回此列表的最后一个元素。 | -                           |

### 2.3 Vector

*   `Vector` 是一个较早的 `List` 实现类 (从 JDK 1.0 开始)。其底层也是基于**`动态数组`**实现的。

*   **特点**：
    
    *   **线程安全**：`Vector` 的大多数方法都使用 `synchronized` 关键字修饰，因此是线程安全的。但也正因如此，其性能通常低于 `ArrayList`。
    
    *   与 `ArrayList` 的功能相似，但由于性能和历史原因，在新代码中已不推荐使用。
    
        如果需要线程安全的列表，可以考虑使用 `Collections.synchronizedList(new ArrayList<>())` 或 `java.util.concurrent` 包下的并发集合 (如 `CopyOnWriteArrayList`)。
    
*   **一些特有方法 (命名风格较早)**：

    | 方法签名                                 | 功能描述                                                     | 参数说明                                         |
    | :--------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------- |
    | `void addElement(E obj)`                 | 将指定的组件添加到此向量的末尾，将其大小增加一。 (等效于 `add(E)`) | `obj`：要添加的组件                              |
    | `void insertElementAt(E obj, int index)` | 将指定对象作为此向量中的组件插入到指定的 `index` 处。 (等效于 `add(int, E)`) | `obj`：要插入的对象<br>`index`：插入新组件的位置 |
    | `void setElementAt(E obj, int index)`    | 将此向量中指定 `index` 处的组件设置为指定的对象。 (等效于 `set(int, E)`) | `obj`：组件要设置成的内容<br>`index`：指定的索引 |
    | `boolean removeElement(Object obj)`      | 从此向量中移除参数的第一个 (索引最小的) 匹配项。 (等效于 `remove(Object)`) | `obj`：要移除的组件                              |
    | `void removeAllElements()`               | 从此向量中移除所有组件并将其大小设置为零。 (等效于 `clear()`) | -                                                |

**实现类选择建议**：
*   默认情况下，优先选择 `ArrayList`，因为它在随机访问方面性能优秀。
*   如果需要频繁地在列表的开头、中间进行插入或删除操作，`LinkedList` 可能是更好的选择。
*   避免在新代码中使用 `Vector`，除非有特定的兼容性需求或是在维护旧代码。对于线程安全的需求，有更好的现代替代方案。
