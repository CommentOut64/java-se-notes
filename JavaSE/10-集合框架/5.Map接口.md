## 1. Map 接口

### 1.1. 概述与 Key-Value 特点

`java.util.Map` 接口用于存储具有映射关系 (key-value) 的数据。它与 `Collection` 接口是 Java 集合框架中两条主要的接口线。

**常用实现类**: `HashMap` (最常用)、`LinkedHashMap`、`TreeMap`、`Hashtable`、`Properties`。

**Key-Value**:

-   `key` (键): 在 `Map` 中唯一，不允许重复。通常使用 `String` 类型作为键。键所在的类需要正确实现 `hashCode()` 和 `equals()` 方法以保证其唯一性。
-   `value` (值): 可以重复。值所在的类建议重写 `equals()` 方法。
-   一个 `key` 对应一个 `value`，它们共同构成一个 `Map.Entry` 对象。

**以 `HashMap` 为例的 Key-Value 特点**:

-   `key` 通过 `Set` 存放，不允许重复。
-   `value` 构成 `Collection` 集合
-   `key` 和 `value` 之间是单向一对一关系。
-   `key` 和 `value` 都可以是任何引用类型，`HashMap` 允许 `key` 和 `value` 为 `null`。
-   所有 `Entry` 对象之间是无序的 (不保证存取顺序)、不可重复的。

### 1.2. 常用方法

| 方法签名                                       | 功能描述                                                     | 参数说明                                                |
| :--------------------------------------------- | :----------------------------------------------------------- | :------------------------------------------------------ |
| `V put(K key, V value)`                        | 将指定的 key-value 对添加到 Map 中，或修改现有 key 对应的 value。 | `key`: 要关联的键。<br>`value`: 要关联的值。            |
| `void putAll(Map<? extends K, ? extends V> m)` | 将指定 Map 中的所有 key-value 对存放到当前 Map 中。          | `m`: 包含要存储元素的 Map。                             |
| `V remove(Object key)`                         | 移除指定 key 对应的 key-value 对，并**返回被移除的 value**。 | `key`: 要移除其映射关系的键。                           |
| `void clear()`                                 | 清空当前 Map 中的所有数据。                                  | -                                                       |
| `V get(Object key)`                            | 获取指定 key 对应的 value。如果 Map 不包含该 key 的映射，则返回 `null`。 | `key`: 要获取其关联值的键。                             |
| `V getOrDefault(Object key, V defaultValue)`   | 如果映射中包含指定键，则返回对应的值；否则返回默认值(JDK 8+) | `key`：要查找的键<br>`defaultValue`：键不存在时返回的值 |
| `boolean containsKey(Object key)`              | 判断 Map 是否包含指定的 key。                                | `key`: 要检查是否存在的键。                             |
| `boolean containsValue(Object value)`          | 判断 Map 是否包含一个或多个指定 value 的映射。               | `value`: 要检查是否存在的值。                           |
| `int size()`                                   | 返回 Map 中 key-value 对的个数。                             | -                                                       |
| `boolean isEmpty()`                            | 判断当前 Map 是否为空。                                      | -                                                       |
| `Set<K> keySet()`                              | 返回 Map 中所有 key 构成的 `Set` 集合。                      | -                                                       |
| `Collection<V> values()`                       | 返回 Map 中所有 value 构成的 `Collection` 集合。             | -                                                       |
| `Set<Map.Entry<K, V>> entrySet()`              | 返回 Map 中所有 key-value 对 (`Map.Entry`) 构成的 `Set` 集合。 | -                                                       |

**基本操作示例**:

````java
import java.util.HashMap;
import java.util.Map;
import java.util.Set;
import java.util.Collection;

public class MapOperations {
    public static void main(String[] args) {
        Map<String, String> map = new HashMap<>();

        // 添加元素
        map.put("CN", "中国");
        map.put("US", "美国");
        map.put("RU", "俄罗斯");
        System.out.println("初始Map: " + map); // {US=美国, CN=中国, RU=俄罗斯} (顺序不保证)

        // 修改元素
        map.put("US", "美利坚合众国");
        System.out.println("修改后US的值: " + map.get("US")); // 美利坚合众国

        // 删除元素
        String removedValue = map.remove("RU");
        System.out.println("移除RU后返回的值: " + removedValue); // 俄罗斯
        System.out.println("移除RU后的Map: " + map); // {US=美利坚合众国, CN=中国}

        // 查询元素
        System.out.println("是否包含键CN: " + map.containsKey("CN")); // true
        System.out.println("Map大小: " + map.size()); // 2

        // 遍历键
        System.out.println("所有的键:");
        Set<String> keys = map.keySet();
        for (String key : keys) {
            System.out.println(key + " -> " + map.get(key));
        }

        // 遍历值
        System.out.println("所有的值:");
        Collection<String> values = map.values();
        for (String value : values) {
            System.out.println(value);
        }

        // 遍历Entry
        System.out.println("所有的映射关系 (Entry):");
        Set<Map.Entry<String, String>> entries = map.entrySet();
        for (Map.Entry<String, String> entry : entries) {
            System.out.println(entry.getKey() + " ===> " + entry.getValue());
        }

        map.clear();
        System.out.println("清空后Map是否为空: " + map.isEmpty()); // true
    }
}
````

## 2. HashMap

`HashMap` 是 `Map` 接口使用频率最高的实现类。

-   **底层结构**: 基于哈希表实现 (JDK 7 中为数组 + 链表，JDK 8 中为数组 + 链表 + 红黑树)。
-   **线程安全性**: 线程不安全。如需线程安全，可使用 `Collections.synchronizedMap(new HashMap<>())` 或 `ConcurrentHashMap`。
-   **null 值**: 允许 `null` 键和 `null` 值 (键 `null` 只能有一个)。
-   **顺序**: 不保证元素的存储和迭代顺序。
-   **性能**: 增删改查操作通常具有较高的性能 (平均时间复杂度 O(1))，前提是哈希函数设计良好且无大量哈希冲突。
-   **Key 的要求**: 键对象必须正确实现 `hashCode()` 和 `equals()` 方法。如果两个 `key` 的 `hashCode()` 值相同并通过 `equals()` 方法比较返回 `true`，则视为同一个 `key`。

**示例：统计字符出现次数**

````java
import java.util.HashMap;
import java.util.Map;

public class WordCount {
    public static void main(String[] args) {
        String text = "hello world hello java";
        Map<Character, Integer> charCountMap = new HashMap<>();
        for (char c : text.toCharArray()) {
            if (c == ' ') continue; // 忽略空格
            // getOrDefault 方法简化了判断和更新逻辑
            charCountMap.put(c, charCountMap.getOrDefault(c, 0) + 1);
        }
        System.out.println("字符统计结果: " + charCountMap);
        // 输出示例: {r=1, d=1, e=2, w=1, h=2, j=1, v=1, l=4, o=3, a=2} (顺序不保证)
    }
}
````

## 3. LinkedHashMap

`LinkedHashMap` 是 `HashMap` 的子类。

-   **底层结构**: 在 `HashMap` 的哈希表结构基础上，额外维护了一个**双向链表**。
-   **顺序**: 此链表记录了元素的插入顺序 (或访问顺序，取决于构造方式)。因此，遍历 `LinkedHashMap` 时，元素会按照插入时的顺序(或最近访问的顺序)排列。
-   **其他特性**: 与 `HashMap` 类似，允许 `null` 键和 `null` 值，线程不安全。

**示例：保持插入顺序**

````java
import java.util.LinkedHashMap;
import java.util.Map;

public class TestLinkedHashMap {
    public static void main(String[] args) {
        Map<String, Integer> linkedMap = new LinkedHashMap<>();
        linkedMap.put("Apple", 10);
        linkedMap.put("Banana", 5);
        linkedMap.put("Orange", 8);
        linkedMap.put("Apple", 12); // 更新Apple的值

        System.out.println("LinkedHashMap 迭代顺序:");
        for (Map.Entry<String, Integer> entry : linkedMap.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }
        // 输出 (按插入顺序，Apple的值被更新):
        // Apple: 12
        // Banana: 5
        // Orange: 8
    }
}
````

## 4. TreeMap

`TreeMap` 实现了 `SortedMap` 接口，能够确保其元素按照键的顺序进行排序。

-   **底层结构**: 基于**红黑树**实现。
-   **排序**:
    -   **自然排序**: 键的类必须实现 `Comparable` 接口。
    -   **定制排序**: 创建 `TreeMap` 时，可以提供一个 `Comparator` 对象来定义键的排序规则。
-   **Key 的要求**: 键不能为 `null` (除非自定义的 `Comparator` 允许)。键对象必须是可比较的。
-   **线程安全性**: 线程不安全。

**示例：按键排序**

````java
import java.util.TreeMap;
import java.util.Map;

public class TestTreeMap {
    public static void main(String[] args) {
        // 自然排序 (String 实现了 Comparable)
        Map<String, String> treeMap = new TreeMap<>();
        treeMap.put("C", "Cat");
        treeMap.put("A", "Apple");
        treeMap.put("B", "Banana");

        System.out.println("TreeMap (自然排序):");
        for (Map.Entry<String, String> entry : treeMap.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }
        // 输出 (按键字母顺序):
        // A: Apple
        // B: Banana
        // C: Cat

        // 定制排序 (例如，按字符串长度)
        Map<String, String> customSortedMap = new TreeMap<>((s1, s2) -> {
            if (s1.length() != s2.length()) {
                return Integer.compare(s1.length(), s2.length());
            }
            return s1.compareTo(s2); // 长度相同则按字典序
        });
        customSortedMap.put("Pear", "梨");
        customSortedMap.put("Fig", "无花果");
        customSortedMap.put("Blueberry", "蓝莓");

        System.out.println("\nTreeMap (定制排序 - 字符串长度):");
        for (Map.Entry<String, String> entry : customSortedMap.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }
        // 输出 (按键字符串长度，长度相同则按字典序):
        // Fig: 无花果
        // Pear: 梨
        // Blueberry: 蓝莓
    }
}
````

## 5. Hashtable

`Hashtable` 是 `Map` 接口的一个早期实现 (JDK 1.0)。

-   **底层结构**: 与 `HashMap` 类似，基于哈希表 (数组 + 链表)。
-   **线程安全性**: 线程安全，其方法大多是 `synchronized` 的，这会导致在并发环境下的性能开销较大。
-   **null 值**: 不允许 `null` 键和 `null` 值，尝试存入会抛出 `NullPointerException`。
-   **顺序**: 不保证元素的存储和迭代顺序。
-   **迭代器**: `Hashtable` 返回的迭代器 ( `enumerator()` 和 `iterator()` ) 是 fail-fast 的。

> **fail-fast(快速失败)** ：当通过某个迭代器(`Iterator` 或 `Enumeration`)遍历集合时，如果在遍历过程中(除了通过该迭代器自身的 `remove()` 方法)对底层集合进行了结构性修改(增、删元素等)，迭代器会立即检测到这种并发修改，并抛出 `ConcurrentModificationException` 来快速终止程序执行，而不是在后续的操作中出现不可预期的行为或数据不一致。

> **`Hashtable` 与 `HashMap` 的主要区别**:
>
> -   **线程安全性**: `Hashtable` 是线程安全的，`HashMap` 是非线程安全的。
> -   **null 值**: `Hashtable` 不允许 `null` 键或值，`HashMap` 允许一个 `null` 键和多个 `null` 值。
> -   **性能**: 由于 `Hashtable` 的同步机制，其性能通常低于 `HashMap`。
> -   **父类**: `Hashtable` 继承自 `Dictionary` 类 (一个已过时的类)，`HashMap` 继承自 `AbstractMap`。
> -   **迭代**: `HashMap` 的迭代器是 fail-fast 的，而 `Hashtable` 的 `enumerator()` 不是。
> -   **推荐使用**: 在现代 Java 开发中，如果不需要线程安全，推荐使用 `HashMap`。如果需要线程安全的 `Map`，推荐使用 `java.util.concurrent.ConcurrentHashMap`，它提供了比 `Hashtable` 更好的并发性能。
>

## 6. Properties

`Properties` 类是 `Hashtable` 的子类，主要用于处理**属性文件**。

-   **键值类型**: `Properties` 对象中的键和值通常都是 `String` 类型。属性文件中的键值对也是字符串。
-   **用途**: 常用于**读取和写入配置文件** (通常是 `.properties` 文件)。
-   **方法**:
    -   `setProperty(String key, String value)`: 设置属性。
    -   `getProperty(String key)`: 获取属性值。
    -   `getProperty(String key, String defaultValue)`: 获取属性值，如果键不存在则返回默认值。
    -   `load(InputStream inStream)`: 从输入字节流加载属性列表。
    -   `store(OutputStream out, String comments)`: 将属性列表写入输出字节流。

**示例**

````java
import java.util.Properties;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class TestProperties {
    public static void main(String[] args) {
        Properties props = new Properties();

        // 设置属性
        props.setProperty("db.url", "localhost:3306/mydb");
        props.setProperty("db.user", "root");
        props.setProperty("db.password", "secret");

        System.out.println("User: " + props.getProperty("db.user")); // root
        System.out.println("Port (default): " + props.getProperty("db.port", "3306")); // 3306

        // 将属性保存到文件
        try (FileOutputStream fos = new FileOutputStream("config.properties")) {
            props.store(fos, "Database Configuration");
        } catch (IOException e) {
            e.printStackTrace();
        }

        // 从文件加载属性
        Properties loadedProps = new Properties();
        try (FileInputStream fis = new FileInputStream("config.properties")) {
            loadedProps.load(fis);
            System.out.println("\nLoaded URL from file: " + loadedProps.getProperty("db.url")); // localhost:3306/mydb
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
````
