## 1. Collection 接口及方法

### 1.1 Collection 接口概述

`java.util.Collection` 接口是 Java 集合框架的根接口之一。它定义了集合(如 `List`、`Set`)所应具备的基本操作，包括添加、删除、查询元素等。JDK 本身不直接提供 `Collection` 接口的任何直接实现，而是由其更具体的子接口(例如 `java.util.List`、`java.util.Set`)提供具体实现类。`Collection` 接口中定义的方法可用于操作其所有子类型的集合。

只要某个 `Collection` 的**实现类**（如 `ArrayList`、`HashSet`、`TreeSet`、`LinkedList`、`PriorityQueue`）提供了一个以 `Collection<? extends E>` 为参数的构造器，就可以用任何其它 `Collection`（无论它是 `List`、`Set`、`Queue` 还是自定义实现）来“互相转换”

### 1.2 Collection 常用方法


| 方法签名                                        | 功能描述                                                     | 参数说明                                                     |
| :---------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **添加**                                        |                                                              |                                                              |
| `boolean add(E element)`                        | 将指定元素 `element` 添加到此集合中。如果集合因调用而更改，则返回 `true`。 | `element`：要添加到集合中的元素                              |
| `boolean addAll(Collection<? extends E> c)`     | 将指定集合 `c` 中的所有元素添加到此集合中。如果集合因调用而更改，则返回 `true`。 | `c`：包含要添加到此集合的元素的集合                          |
| **删除**                                        |                                                              |                                                              |
| `boolean remove(Object o)`                      | 从此集合中移除指定元素 `o` 的单个实例(如果存在)。如果元素被移除，则返回 `true`。 | `o`：要从此集合中移除的元素                                  |
| `boolean removeAll(Collection<?> c)`            | 移除此集合中那些也包含在指定集合 `c` 中的所有元素(差集)。如果集合因调用而更改，则返回 `true`。 | `c`：包含要从此集合中移除的元素的集合                        |
| `boolean retainAll(Collection<?> c)`            | 仅保留此集合中那些也包含在指定集合 `c` 中的元素(交集)。如果集合因调用而更改，则返回 `true`。 | `c`：包含要保留在此集合中的元素的集合                        |
| `boolean removeIf(Predicate<? super E> filter)` | 移除此集合中所有满足给定判断条件 `filter` 的元素 (JDK 8+)。如果移除了任何元素，则返回 `true`。 | `filter`：一个谓词，如果元素应被移除，则返回 `true`          |
| `void clear()`                                  | 移除此集合中的所有元素。                                     | -                                                            |
| **查找**                                        |                                                              |                                                              |
| `boolean contains(Object o)`                    | 如果此集合包含指定元素 `o`(通过 `equals` 方法判断)，则返回 `true`。 | `o`：要检查其在此集合中是否存在的元素                        |
| `boolean containsAll(Collection<?> c)`          | 如果此集合包含指定集合 `c` 中的所有元素，则返回 `true`。     | `c`：要检查其所有元素是否都包含在此集合中的集合              |
| `boolean equals(Object o)`                      | 将指定对象 `o` 与此集合进行比较以判断是否相等。              | `o`：要与此集合进行相等性比较的对象                          |
| `boolean isEmpty()`                             | 如果此集合不包含任何元素，则返回 `true`。                    | -                                                            |
| `int size()`                                    | 返回此集合中的元素数量。                                     | -                                                            |
| `int hashCode()`                                | 返回此集合的哈希码值。                                       | -                                                            |
| **遍历**                                        |                                                              |                                                              |
| `Object[] toArray()`                            | 返回一个包含此集合中所有元素的 `Object` 类型数组。           | -                                                            |
| `T[] toArray(T[] a)`                            | 返回一个包含此集合中所有元素的数组；返回数组的运行时类型是指定数组 `a` 的运行时类型。如果 `a` 的大小足以容纳集合元素，则元素将存储在 `a` 中；否则，将分配一个具有 `a` 运行时类型和集合大小的新数组。 | `a`：存储此集合元素的数组(如果它足够大)；否则，将为此目的分配一个相同运行时类型的新数组 |
| `Iterator<E> iterator()`                        | 返回在此集合的元素上进行迭代的迭代器。                       | -                                                            |

**方法使用辨析：**

*   `add(element)` 与 `addAll(collection)`：
    *   `add(element)` 向集合中添加单个元素。
    *   `addAll(otherCollection)` 将 `otherCollection` 中的每个元素逐个添加到当前集合中。
    *   **注意**：若执行 `coll.add(otherCollection)`，是将 `otherCollection` 整体作为一个元素添加(如果 `coll` 的元素类型兼容)。这与 `addAll` 的行为不同。

*   删除相关方法：
    *   `remove(Object o)`：删除集合中第一个与 `o` 相等的元素。
    *   `removeAll(Collection<?> c)`：计算当前集合与 `c` 的差集，即 `this = this - c`。
    *   `retainAll(Collection<?> c)`：计算当前集合与 `c` 的交集，即 `this = this ∩ c`。
    *   `clear()`：清空集合。
    *   `removeIf(Predicate filter)` (JDK 8+)：根据条件删除元素，非常便捷。

*   集合与数组转换：
    *   `toArray()`：将集合转换为 `Object[]` 数组。
    *   `toArray(T[] a)`：将集合转换为指定类型 `T` 的数组，更常用且类型安全。
    *   `Arrays.asList(T... arrayElements)`：可将数组或一组离散元素转换为一个 `List`。但需注意，此方法返回的 `List` 是一个固定大小的列表(底层仍是原数组的视图)，不支持 `add` 或 `remove` 等修改结构的操作。

**示例：**

```java
// ArrayList 是 Collection 的一种实现
Collection<String> c1 = new ArrayList<>();
c1.add("Java");
c1.add("Python");

Collection<String> c2 = new ArrayList<>();
c2.add("Go");
c2.add("Java");

// addAll
Collection<String> allLangs = new ArrayList<>(c1);
allLangs.addAll(c2); // allLangs 结果: [Java, Python, Go, Java]

// removeAll
Collection<String> c1Copy = new ArrayList<>(c1);
c1Copy.removeAll(c2); // c1Copy 结果: [Python] (移除了c1和c2共有的"Java")

// retainAll
Collection<String> c1AnotherCopy = new ArrayList<>(c1);
c1AnotherCopy.retainAll(c2); // c1AnotherCopy 结果: [Java] (保留了c1和c2共有的"Java")

// toArray
Object[] objArray = c1.toArray();
String[] strArray = c1.toArray(new String[0]); // 推荐用法，自动调整数组大小
```

## 2. Iterator (迭代器) 接口

### 2.1 Iterator 接口概述

`java.util.Iterator` 接口为遍历 `Collection` 中的元素而设计。`Iterator` 本身不存储元素，其核心功能是按顺序访问集合中的各个元素。

任何实现了 `Collection` 接口的集合类都必须提供一个 `iterator()` 方法，该方法返回一个实现了 `Iterator` 接口的对象。每次调用集合的 `iterator()` 方法都会生成一个**全新的迭代器对象**，其内部通常维护一个游标(或指针)，**初始时指向集合的第一个元素之前**。

### 2.2 Iterator 常用方法

| 方法签名                                              | 功能描述                                                                                                   | 参数说明                                 |
| :---------------------------------------------------- | :--------------------------------------------------------------------------------------------------------- | :--------------------------------------- |
| `boolean hasNext()`                                   | 如果迭代仍有元素可访问，则返回 `true`。                                                                      | -                                        |
| `E next()`                                            | 返回迭代中的下一个元素，并将游标后移。若无下一元素则抛出 `NoSuchElementException`。                                  | -                                        |
| `void remove()`                                       | 从底层集合中移除迭代器最后一次返回的元素。此方法每调用一次 `next()` 后最多只能调用一次。若在不当状态下调用(如未调用 `next()` 或已调用过 `remove()`)，则抛出 `IllegalStateException`。 | -                                        |
| `void forEachRemaining(Consumer<? super E> action)`   | 对迭代器中剩余的每个元素执行给定的操作 `action` (JDK 8+)。                                                       | `action`：要对每个元素执行的操作             |

### 2.3 使用 Iterator 遍历和删除元素

**遍历元素：**
标准的迭代模式是使用 `while` 循环，先通过 `hasNext()` 检查是否存在下一个元素，如果存在，则通过 `next()` 获取该元素。

```java
Collection<String> languages = new ArrayList<>();
languages.add("C++");
languages.add("Rust");
languages.add("Swift");

Iterator<String> iterator = languages.iterator();
while (iterator.hasNext()) {
    String language = iterator.next();
    System.out.println(language);
}
```

**使用 Iterator 删除元素：**
在迭代过程中若要安全地删除集合中的元素，必须使用 `Iterator` 接口提供的 `remove()` 方法。此方法会删除由 `next()` 方法最后返回的那个元素。

*   在调用 `iterator.remove()` 之前，必须先调用 `iterator.next()`。
*   每次调用 `next()` 之后，`remove()` 方法最多只能被调用一次。
*   **严禁**在通过 `Iterator` 遍历时，使用集合对象自身的 `remove()` 方法(例如 `languages.remove(obj)`)来修改集合，这通常会导致 `ConcurrentModificationException` 异常。

```java
Collection<Integer> numbers = new ArrayList<>(Arrays.asList(10, 20, 30, 40, 50));
Iterator<Integer> numIterator = numbers.iterator();
while (numIterator.hasNext()) {
    Integer number = numIterator.next();
    if (number % 20 == 0) { // 删除所有20的倍数
        numIterator.remove(); // 安全删除
    }
}
System.out.println(numbers); // numbers 变为 [10, 30, 50]
```

### 2.4 Collection.removeIf() 方法 (JDK 8+)

JDK 8 在 `Collection` 接口中引入了 `removeIf(Predicate<? super E> filter)` 方法。它提供了一种更简洁的方式来根据指定条件删除集合中的元素，其内部实现通常也是安全的，避免了手动管理迭代器的复杂性。

```java
Collection<String> frameworks = new ArrayList<>(Arrays.asList("Spring", "Django", "React", "Vue"));
// 删除所有名称长度小于5的框架
frameworks.removeIf(fw -> fw.length() < 5);
// frameworks 变为 ["Spring", "Django", "React"]
System.out.println(frameworks);
```

## 3. foreach 循环 (增强 for 循环)

### 3.1 foreach 循环概述

JDK 5.0 引入了 `foreach` 循环(也称为增强 `for` 循环)，它提供了一种更简洁的语法来遍历数组和实现了 `java.lang.Iterable` 接口的对象(`Collection` 接口继承了 `Iterable`)。

数组也能使用，但本身未实现 `Iterable` 接口

### 3.2 语法格式

```java
for (元素类型 循环变量 : 数组或实现了Iterable接口的集合对象) {
    // 使用循环变量执行操作
}
```

**示例：**

```java
// 遍历集合
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
for (String name : names) {
    System.out.println(name);
}

// 遍历数组
int[] scores = {90, 85, 92};
for (int score : scores) {
    System.out.println(score);
}
```

### 3.3 foreach 循环与 Iterator

当 `foreach` 循环用于遍历 `Collection` 时，其底层实际上是由编译器转换为使用 `Iterator` 来完成的。因此，它享有与 `Iterator` 相同的遍历行为。

### 3.4 注意事项

*   **修改集合限制**：`foreach` 循环主要设计用于**遍历读取元素**。在循环体内，**不应**通过集合对象自身的方法(如 `add()`、`remove()`)来修改集合的结构(特别是增删元素)。这样做极易引发 `ConcurrentModificationException`。

    如果需要在遍历时删除元素，应回退到使用显式的 `Iterator` 并调用其 `remove()` 方法，或者在循环外部使用 `Collection.removeIf()`。

*   **循环变量是副本(对于基本类型)或引用的副本(对于对象类型)**：
    
    *   当遍历基本类型数组时，修改循环变量的值不会影响原数组。
    *   当遍历对象集合或对象数组时，循环变量持有的是对集合中对象的引用的一个副本。通过这个引用修改对象的状态(如果对象是可变的)会影响原始对象。但如果对循环变量本身重新赋值(例如 `loopVar = newObject;` 或 `loopVar = null;`)，这只会改变循环变量的指向，并不会改变集合中原始对象的引用。
    
    ```java
    // 示例1: 修改对象类型的循环变量的引用
    List<String> stringList = new ArrayList<>(Arrays.asList("one", "two"));
    for (String s : stringList) {
        s = "three"; // s 指向了新的字符串 "three"，stringList 中的元素未改变
    }
    System.out.println(stringList); // 输出: [one, two]
    
    // 示例2: 修改可变对象的内容
    List<StringBuilder> sbList = new ArrayList<>(Arrays.asList(new StringBuilder("a"), new StringBuilder("b")));
    for (StringBuilder sb : sbList) {
        sb.append("z"); // 修改了 StringBuilder 对象的内容
    }
    System.out.println(sbList); // 输出: [az, bz]
    ```
