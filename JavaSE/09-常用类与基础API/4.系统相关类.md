

## 1.1 `java.lang.System` 类

`System` 类代表 Java 程序运行的系统环境，提供了访问系统级属性和执行系统级操作的方法。该类位于 `java.lang` 包，无需显式导入。

-   由于其构造器是私有的 (`private`)，因此无法创建 `System` 类的对象。
-   其所有有用的成员变量和方法都是静态的 (`static`)，可以直接通过类名调用。

### 1.1.1 成员变量

`System` 类提供了三个标准流对象：

-   `static final InputStream in`: 标准输入流，通常对应键盘输入。
    
    ```java
    // 示例：从键盘读取输入
    Scanner scanner = new Scanner(System.in);
    String input = scanner.nextLine();
    ```
-   `static final PrintStream out`: 标准输出流，通常对应显示器输出。
    
    ```java
    // 示例：向控制台输出信息
    System.out.println("Hello, World!");
    ```
-   `static final PrintStream err`: 标准错误输出流，通常也对应显示器输出，用于显示错误信息。
    ```java
    // 示例：向控制台输出错误信息
    System.err.println("An error occurred.");
    ```

### 1.1.2 常用成员方法

| 方法签名                                                     | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `static long currentTimeMillis()`                            | 返回当前时间与协调世界时 (UTC) 1970年1月1日午夜之间的毫秒差。 | -                                                            |
| `static void exit(int status)`                               | 终止当前正在运行的 Java 虚拟机。                             | `status`：退出状态码。<br>非零状态码表示异常终止，0 表示正常终止。 |
| `static void gc()`                                           | 运行垃圾回收器。调用此方法只是建议 JVM 进行垃圾回收，JVM 是否立即执行以及如何执行取决于其内部实现。 | -                                                            |
| `static String getProperty(String key)`                      | 获取指定键指示的系统属性。                                   | `key`：系统属性的名称。                                      |
| `static String getProperty(String key, String def)`          | 获取指定键指示的系统属性。如果属性不存在，则返回默认值。     | `key`：系统属性的名称。<br>`def` (可选)：如果属性未找到，则返回此默认值。 |
| `static java.util.Properties getProperties()`                | 获取当前所有的系统属性。                                     | -                                                            |
| `static String getenv(String name)`                          | 获取指定环境变量的值。                                       | `name`：环境变量的名称。                                     |
| `static java.util.Map<String,String> getenv()`               | 获取一个包含当前所有环境变量的不可修改的字符串映射视图。     | -                                                            |
| `static void arraycopy(Object src, int srcPos, Object dest, int destPos, int length)` | 从源数组中复制一个子数组到目标数组的指定位置。               | `src`：源数组。<br>`srcPos`：源数组中的起始位置 (索引)。<br>`dest`：目标数组。<br>`destPos`：目标数据中的起始位置 (索引)。<br>`length`：要复制的数组元素的数量。 |

> JVM 的垃圾回收器经过精心优化，一般情况下比人工干预更有效、更稳定。大量研究和实践都表明，随意调用会打乱 GC 的自适应策略，反而可能导致更频繁的停顿。

**常见的系统属性键 (Key)：**

| 属性键           | 描述                         |
| :--------------- | :--------------------------- |
| `java.version`   | Java 运行时环境版本          |
| `java.home`      | Java 安装目录                |
| `java.vendor`    | Java 运行时环境供应商        |
| `os.name`        | 操作系统的名称               |
| `os.version`     | 操作系统的版本               |
| `os.arch`        | 操作系统的架构               |
| `user.name`      | 用户的账户名称               |
| `user.home`      | 用户的主目录                 |
| `user.dir`       | 用户的当前工作目录           |
| `file.separator` | 文件分隔符 (如 `/` 或 `\`)   |
| `path.separator` | 路径分隔符 (如 `:` 或 `;`)   |
| `line.separator` | 行分隔符 (如 `\n` 或 `\r\n`) |

```java
public class SystemDemo {
    public static void main(String[] args) {
        // 获取当前时间戳
        long startTime = System.currentTimeMillis();
        System.out.println("当前时间戳: " + startTime);

        // 获取系统属性
        System.out.println("Java 版本: " + System.getProperty("java.version"));
        System.out.println("操作系统: " + System.getProperty("os.name"));
        System.out.println("用户目录: " + System.getProperty("user.home"));

        // 数组复制示例
        int[] sourceArray = {1, 2, 3, 4, 5};
        int[] destinationArray = new int[5];
        System.arraycopy(sourceArray, 1, destinationArray, 2, 2); // 从 sourceArray[1] 开始复制2个元素到 destinationArray[2]
        // destinationArray 内容将是: [0, 0, 2, 3, 0]
        System.out.println("复制后的数组: " + java.util.Arrays.toString(destinationArray));
        
        // System.gc(); // 建议进行垃圾回收

        // System.exit(0); // 正常退出程序
        // System.out.println("这行代码不会执行");
    }
}
```
*注意：`Object.finalize()` 方法自 Java 9 起已被弃用，不应依赖它进行资源清理。现代 Java 中推荐使用 `try-with-resources` 语句或 `java.lang.ref.Cleaner` (自 Java 9 起) 进行资源管理。*

## 1.2 `java.lang.Runtime` 类

`Runtime` 类允许 Java 应用程序与其运行的环境进行交互。每个 Java 应用程序都有一个 `Runtime` 类的单一实例。

-   应用程序不能创建自己的 `Runtime` 实例，但可以通过 `Runtime.getRuntime()` 方法获取当前运行时对象。

### 1.2.1 常用成员方法

| 方法签名                                                     | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `static Runtime getRuntime()`                                | 返回与当前 Java 应用程序相关的运行时对象。                   | -                                                            |
| `long totalMemory()`                                         | 返回 Java 虚拟机中的初始化总内存量 (以字节为单位)。此值可能随时间变化。 | -                                                            |
| `long maxMemory()`                                           | 返回 Java 虚拟机可以尝试使用的最大内存量 (以字节为单位)。    | -                                                            |
| `long freeMemory()`                                          | 返回 Java 虚拟机中的空闲内存量 (以字节为单位)。调用 `gc()` 可能增加此值。 | -                                                            |
| `int availableProcessors()`                                  | 返回 Java 虚拟机可用的处理器数量。                           | -                                                            |
| `void gc()`                                                  | 运行垃圾回收器 (与 `System.gc()` 效果类似)。                 | -                                                            |
| `void exit(int status)`                                      | 终止当前运行的 Java 虚拟机 (与 `System.exit(int)` 效果类似)。 | `status`：退出状态码。                                       |
| `Process exec(String command)`                               | 在单独的进程中执行指定的字符串命令。                         | `command`：要执行的系统命令。                                |
| `Process exec(String[] cmdarray)`                            | 在单独的进程中执行指定的命令和参数。                         | `cmdarray`：包含命令及其参数的字符串数组。                   |
| `Process exec(String command, String[] envp, java.io.File dir)` | 在具有指定环境和工作目录的单独进程中执行指定的字符串命令。   | `command`：要执行的系统命令。<br>`envp` (可选)：字符串数组，每个元素格式为 `name=value`，用于设置子进程的环境变量。<br>`dir` (可选)：子进程的工作目录。 |

```java
public class RuntimeDemo {
    public static void main(String[] args) {
        Runtime runtime = Runtime.getRuntime();

        long maxMem = runtime.maxMemory() / 1024 / 1024; // MB
        long totalMem = runtime.totalMemory() / 1024 / 1024; // MB
        long freeMem = runtime.freeMemory() / 1024 / 1024; // MB

        System.out.println("最大可用内存 (Max Memory): " + maxMem + " MB");
        System.out.println("当前分配总内存 (Total Memory): " + totalMem + " MB");
        System.out.println("当前空闲内存 (Free Memory): " + freeMem + " MB");
        System.out.println("已用内存: " + (totalMem - freeMem) + " MB");
        System.out.println("可用处理器数量: " + runtime.availableProcessors());

        /*
        try {
            // 示例：执行外部命令 (Windows下打开记事本)
            // Process process = runtime.exec("notepad.exe");
            // process.waitFor(); // 等待命令执行完成
            // System.out.println("记事本已关闭。");
        } catch (java.io.IOException e) {
            System.err.println("执行命令出错: " + e.getMessage());
        } catch (InterruptedException e) {
            System.err.println("等待进程中断: " + e.getMessage());
            Thread.currentThread().interrupt(); // 恢复中断状态
        }
        */
    }
}
```
