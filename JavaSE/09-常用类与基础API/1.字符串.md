## 1. 不可变字符序列 String

### 1.1 String 的特性

-   `java.lang.String` 类用于表示字符串。Java 中所有字符串字面量(如 `"hello"`)都是此类的实例。
-   字符串是**常量**，其值在创建后不能更改。
-   `String` 类被 `final` 修饰，**不能被继承**。
-   **底层存储**：
    
    -   JDK 8 及更早版本：`private final char value[]`。
        
        `private` 和 `final` 修饰，且没有提供修改数组内容的方法，保证了 `String` 对象的不可变性。修改字符串实际上是创建新的 `String` 对象。
    -   JDK 9 及更高版本：`private final byte[] value`，并配合一个编码标志(`coder`)。
        
        根据字符串内容，字符可以以 Latin-1 (单字节) 或 UTF-16 (双字节) 编码存储，以优化空间。
-   Java 对字符串拼接(`+`)和对象转字符串(`toString()`)提供特殊支持。

### 1.2 String 的内存结构

-   **字符串常量池 (String Pool)**：
    
    由于 `String` 的不可变性，JVM 维护了一个字符串常量池来存储字符串字面量和通过 `intern()` 方法添加的字符串，以实现共享，减少内存开销。
    
    位置：
    -   JDK 6 及之前：方法区 (永久代)。
    -   JDK 7 及之后：堆空间。
    
-   **创建字符串的方式**：
    
    1.  **字面量赋值**:
        
        ```java
        String s1 = "hello";
        String s2 = "hello";
        System.out.println(s1 == s2); // true，s1 和 s2 指向常量池中同一个 "hello"
        ```
    2.  **`new` 关键字**:
        
        ```java
        String s3 = new String("hello");
        String s4 = new String("hello");
        System.out.println(s1 == s3); // false，s3 指向堆中新对象
        System.out.println(s3 == s4); // false，s3 和 s4 指向堆中不同对象
        ```
        `new String("text")`：至少在堆中创建一个新的 `String` 对象。如果 "text" 字面量之前未在常量池中，则还会在常量池中创建一个 "text" 对象。
    
-   **`intern()` 方法**：
    
    当调用一个 `String` 对象的 `intern()` 方法时：
    -   如果常量池中已存在一个与此 `String` 对象内容相同的字符串，则返回常量池中该字符串的引用。
    -   否则，将此 `String` 对象的内容添加到常量池中，并返回常量池中新创建的字符串的引用。
    
    ```java
    String s1 = new String("world");
    String s2 = "world";
    System.out.println(s1 == s2); // false
    String s3 = s1.intern();
    System.out.println(s2 == s3); // true
    ```
    
-   **字符串拼接规则**：
    
    -   **常量 + 常量**：结果在常量池，编译期优化。
        
        ```java
        String a = "java" + "script"; // "javascript" 在常量池
        String b = "javascript";
        System.out.println(a == b); // true
        ```
    -   **变量 + 常量 / 变量 + 变量**：结果在堆中(实际通过 `StringBuilder` 实现后调用 `toString()` 创建新 `String` 对象)。
        
        ```java
        String s = "java";
        String c = s + "script"; // 在堆中创建新对象 "javascript"
        System.out.println(b == c); // false
        ```
    -   若拼接中的变量是 `final` 修饰的，则视为常量：
        ```java
        final String finalStr = "java";
        String d = finalStr + "script"; // "javascript" 在常量池
        System.out.println(b == d); // true
        ```
    -   `concat()` 方法：即使操作数都是常量字符串，结果也在**堆**中。
        
        ```java
        String e = "java".concat("script"); // 在堆中创建新对象 "javascript"
        System.out.println(b == e); // false
        ```
-   **String 的不可变性体现**：
    
    ```java
    // 方法参数传递时，String对象引用的副本被传递。
    // 在方法内对String参数重新赋值，不会影响方法外的原始String对象。
    public class StringPassTest {
        public static void change(String str, char ch[]) {
            str = "test ok"; // str 指向新的 "test ok" 对象，main中的str不受影响
            ch[0] = 'b';     // ch 数组内容被修改
        }
        public static void main(String[] args) {
            String originalStr = "good";
            char[] originalCh = { 't', 'e', 's', 't' };
            change(originalStr, originalCh);
            System.out.println(originalStr); // 输出 "good"
            System.out.println(new String(originalCh)); // 输出 "best"
        }
    }
    ```

### 1.3 String 的常用 API

#### 1.3.1 构造器

| 构造器签名                                      | 描述                                                                 |
| :---------------------------------------------- | :------------------------------------------------------------------- |
| `public String()`                               | 初始化为空字符序列。                                                 |
| `public String(String original)`                | 创建参数字符串的副本。                                               |
| `public String(char[] value)`                   | 使用字符数组内容创建字符串。                                         |
| `public String(char[] value, int offset, int count)` | 使用字符数组指定范围 (`offset` 起始，`count` 个数) 的内容创建字符串。 |
| `public String(byte[] bytes)`                   | 使用平台默认字符集解码字节数组创建字符串。                           |
| `public String(byte[] bytes, String charsetName)` | 使用指定字符集解码字节数组创建字符串。                               |

#### 1.3.2 String 与其他结构间的转换

1. **字符串 -> 基本数据类型/包装类**：使用包装类的 `parseXXX(String s)` 方法，如 `Integer.parseInt("123")`。
2. **基本数据类型/包装类 -> 字符串**：使用 `String.valueOf(...)` 方法或通过 `+ ""` 操作。
3. **字符数组 <-> 字符串**：
   
    -   字符数组 -> 字符串：使用构造器 `String(char[])` 或 `String(char[], offset, count)`。
    -   字符串 -> 字符数组：`char[] arr = str.toCharArray();`。
4. **字节数组 <-> 字符串 (编码与解码)**：
   
    -   字符串 -> 字节数组 (编码)：
        -   `byte[] bytes = str.getBytes();`: 使用平台默认字符集。
        -   `byte[] bytes = str.getBytes(String charsetName);`: 使用指定字符集。
    -   字节数组 -> 字符串 (解码)：使用构造器 `String(byte[])`、`String(byte[], charsetName)` 等。
    ```java
    // 编码解码示例
    String str = "你好";
    try {
        byte[] utf8Bytes = str.getBytes("UTF-8"); // 编码
        String decodedStr = new String(utf8Bytes, "UTF-8"); // 解码
        System.out.println(decodedStr); // 你好
    } catch (java.io.UnsupportedEncodingException e) {
        e.printStackTrace();
    }
    ```

import java.util.Scanner;
import java.util.Random;

public class StringCommonMethods {
    public static void main(String[] args) {
        String s1 = "  Hello World  ";

        String s5 = "Banana";
        System.out.println("s4.compareTo(s5): " + s4.compareTo(s5)); // 正值 (a > B)

        StringBuilder codeBuilder = new StringBuilder();

        for (int i = 0; i < 4; i++) {
            codeBuilder.append(chars[random.nextInt(chars.length)]);
        }
        String generatedCode = codeBuilder.toString();
        System.out.println("生成的验证码: " + generatedCode);

        Scanner scanner = new Scanner(System.in);
        System.out.print("请输入验证码: ");
        String inputCode = scanner.nextLine();

        if (generatedCode.equalsIgnoreCase(inputCode.trim())) {
            System.out.println("验证码正确！");
        } else {
            System.out.println("验证码错误。");
        }
        scanner.close();
    }

##### 2. 查找操作

| 方法签名                                     | 功能描述                                                     | 参数说明                                   |
| :------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------- |
| `boolean contains(CharSequence s)`           | 判断此字符串是否包含指定的字符序列                             | `s`：要检查的字符序列                      |
| `int indexOf(String str)`                    | 返回指定子字符串在此字符串中首次出现的索引(未找到返回-1)          | `str`：要查找的子字符串                    |
| `int indexOf(String str, int fromIndex)`     | 从指定索引开始，返回指定子字符串在此字符串中首次出现的索引(未找到返回-1) | `str`：要查找的子字符串<br>`fromIndex`：开始查找的索引 |
| `int lastIndexOf(String str)`                | 返回指定子字符串在此字符串中最后一次出现的索引(未找到返回-1)        | `str`：要查找的子字符串                    |
| `int lastIndexOf(String str, int fromIndex)` | 从指定索引开始反向搜索，返回指定子字符串在此字符串中最后一次出现的索引(未找到返回-1) | `str`：要查找的子字符串<br>`fromIndex`：开始反向查找的索引 |

```java
public class StringSearchMethods {
    public static void main(String[] args) {
        String text = "The quick brown fox jumps over the lazy dog. The fox is quick.";

        System.out.println("包含 \"fox\": " + text.contains("fox")); // true
        System.out.println("包含 \"cat\": " + text.contains("cat")); // false

        System.out.println("\"fox\" 首次出现位置: " + text.indexOf("fox")); // 16
        System.out.println("从索引 20 开始查找 \"fox\": " + text.indexOf("fox", 20)); // 41

        System.out.println("\"The\" 最后出现位置: " + text.lastIndexOf("The")); // 41
        // 从索引 30 开始反向搜索 "The" (即在 "The quick brown fox jumps over the" 中搜索)
        System.out.println("从索引 30 反向查找 \"The\": " + text.lastIndexOf("The", 30)); // 0
        System.out.println("\"quick\" 最后出现位置: " + text.lastIndexOf("quick")); // 50
    }
}
```

##### 3. 截取操作

| 方法签名                                         | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `String substring(int beginIndex)`               | 返回一个新的字符串，它是此字符串从 `beginIndex` 开始截取到最后的一个子字符串。 | `beginIndex`：起始索引(包含)                                 |
| `String substring(int beginIndex, int endIndex)` | 返回一个新字符串，它是此字符串从 `beginIndex` 开始截取到 `endIndex`(不包含)的一个子字符串。 | `beginIndex`：起始索引(包含)<br>`endIndex`：结束索引(不包含) |

> Java中所有区间都是`左开右闭`
```java
public class StringSubstringMethods {
    public static void main(String[] args) {
        String data = "ProgrammingJava";

        String sub1 = data.substring(11);
        System.out.println("从索引 11 截取到末尾: " + sub1); // "Java"

        String sub2 = data.substring(0, 11);
        System.out.println("从索引 0 截取到索引 11 (不含): " + sub2); // "Programming"

        String fileName = "document.report.pdf";
        int lastDotIndex = fileName.lastIndexOf(".");
        if (lastDotIndex != -1) {
            String nameWithoutExtension = fileName.substring(0, lastDotIndex);
            String extension = fileName.substring(lastDotIndex + 1);
            System.out.println("文件名: " + nameWithoutExtension); // "document.report"
            System.out.println("后缀名: " + extension);         // "pdf"
        }
    }
}
```

##### 4. 字符与字符数组操作

| 方法签名                                                     | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `char charAt(int index)`                                     | 返回指定索引位置的字符                                       | `index`：字符的索引                                          |
| `char[] toCharArray()`                                       | 将此字符串转换为一个新的字符数组返回                         | -                                                            |
| `static String valueOf(char[] arr)`                          | 返回表示指定字符数组中字符序列的 `String`                    | `arr`：字符数组                                              |
| `static String valueOf(char[] arr, int offset, int count)`   | 返回表示指定字符数组的指定子数组中字符序列的 `String`        | `arr`：字符数组<br>`offset`：子数组的初始偏移量<br>`count`：子数组的长度 |
| `static String copyValueOf(char[] arr)`                      | [已过时]返回表示指定字符数组中字符序列的 `String`            | `arr`：字符数组                                              |
| `static String copyValueOf(char[] arr, int offset, int count)` | [已过时]返回表示指定字符数组的指定子数组中字符序列的 `String` | `arr`：字符数组<br>`offset`：子数组的初始偏移量<br>`count`：子数组的长度 |

```java
import java.util.Arrays;

public class StringCharMethods {
    public static void main(String[] args) {
        String text = "Example";

        System.out.println("索引 0 处的字符: " + text.charAt(0)); // 'E'
        System.out.println("索引 3 处的字符: " + text.charAt(3)); // 'm'

        char[] charArray = text.toCharArray();
        System.out.println("转换为字符数组: " + Arrays.toString(charArray)); // [E, x, a, m, p, l, e]

        // 将字符数组排序后转回字符串
        Arrays.sort(charArray);
        String sortedText = new String(charArray); // 或者 String.valueOf(charArray)
        System.out.println("排序后的字符串: " + sortedText); // "Eaelmpx"

        // 将首字母转大写 (假设字符串非空)
        String name = "alice";
        if (name != null && !name.isEmpty()) {
            String capitalizedName = Character.toUpperCase(name.charAt(0)) + name.substring(1);
            System.out.println("首字母大写: " + capitalizedName); // "Alice"
        }

        char[] data = {'J', 'a', 'v', 'a', ' ', 'i', 's', ' ', 'F', 'u', 'n'};
        String fromChars1 = String.valueOf(data);
        System.out.println("valueOf(data): " + fromChars1); // "Java is Fun"

        String fromChars2 = String.valueOf(data, 0, 4);
        System.out.println("valueOf(data, 0, 4): " + fromChars2); // "Java"

        // copyValueOf 功能与 valueOf 类似，但通常推荐使用 valueOf
        String fromCopyChars1 = String.copyValueOf(data);
        System.out.println("copyValueOf(data): " + fromCopyChars1); // "Java is Fun"
        String fromCopyChars2 = String.copyValueOf(data, 8, 3);
        System.out.println("copyValueOf(data, 8, 3): " + fromCopyChars2); // "Fun"

        int number = 2024;
        String numStr = String.valueOf(number);
        System.out.println("数字转字符串: " + numStr); // "2024"
    }
}
```

##### 6. 替换操作

| 方法签名                                                       | 功能描述                                                     | 参数说明                                                     |
| :------------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `String replace(char oldChar, char newChar)`                   | 返回一个新字符串，通过用 `newChar` 替换此字符串中所有出现的 `oldChar` 得到。 | `oldChar`：旧字符<br>`newChar`：新字符                        |
| `String replace(CharSequence target, CharSequence replacement)` | 使用指定的字面值替换序列替换此字符串所有匹配字面值目标序列的子字符串。 | `target`：要被替换的字符序列<br>`replacement`：替换的字符序列 |
| `String replaceAll(String regex, String replacement)`          | 使用给定的 `replacement` 替换此字符串所有匹配给定正则表达式 `regex` 的子字符串。 | `regex`：正则表达式<br>`replacement`：替换字符串            |
| `String replaceFirst(String regex, String replacement)`        | 使用给定的 `replacement` 替换此字符串匹配给定正则表达式 `regex` 的第一个子字符串。 | `regex`：正则表达式<br>`replacement`：替换字符串            |

```java
public class StringReplaceMethods {
    public static void main(String[] args) {
        String text1 = "hello world, hello java";

        String replaced1 = text1.replace('l', 'L');
        System.out.println("将 'l' 替换为 'L': " + replaced1); // "heLLo worLd, heLLo java"

        String replaced2 = text1.replace("hello", "Hi");
        System.out.println("将 \"hello\" 替换为 \"Hi\": " + replaced2); // "Hi world, Hi java"

        String text2 = "item1,item2, item3";
        // 使用正则表达式替换所有逗号及其后的可选空格为单个逗号
        String replacedAll = text2.replaceAll(",\\s*", ",");
        System.out.println("规范化逗号: " + replacedAll); // "item1,item2,item3"

        String text3 = "The price is $100 and then $200.";
        // 只替换第一个匹配到的价格数字
        String replacedFirst = text3.replaceFirst("\\$\\d+", "[$REPLACED]");
        System.out.println("替换第一个价格: " + replacedFirst); // "The price is [$REPLACED] and then $200."

        String messyData = "  user@example.com  ";
        // 去除非字母数字和@.的字符，并转小写，去除首尾空格
        String cleanEmail = messyData.replaceAll("[^a-zA-Z0-9@.]", "").toLowerCase().trim();
        System.out.println("清理后的邮件: " + cleanEmail); // "user@example.com"
    }
}
```
### 1.4 常见算法题目

1.  **模拟 trim 方法**
    
    ```java
    public String myTrim(String str) {
        if (str == null) return null;
        int start = 0, end = str.length() - 1;
        while (start <= end && Character.isWhitespace(str.charAt(start))) start++;
        while (start <= end && Character.isWhitespace(str.charAt(end))) end--;
        return str.substring(start, end + 1);
    }
    ```
    
2.  **反转字符串指定部分** (例如 "abcdefg" 反转索引2到5，变为 "abfedcg")
    
    ```java
    public String reverseRange(String str, int start, int end) {
        if (str == null || start < 0 || end >= str.length() || start >= end) return str;
        char[] arr = str.toCharArray();
        while (start < end) {
            char temp = arr[start];
            arr[start] = arr[end];
            arr[end] = temp;
            start++;
            end--;
        }
        return new String(arr);
    }
    ```
    
3.  **获取子串在主串中出现的次数**
    
    ```java
    public int countOccurrences(String mainStr, String subStr) {
        if (mainStr == null || subStr == null || mainStr.length() < subStr.length() || subStr.isEmpty()) {
            return 0;
        }
        int count = 0;
        int index = 0;
        while ((index = mainStr.indexOf(subStr, index)) != -1) {
            count++;
            index += subStr.length();
        }
        return count;
    }
    ```

## 2. 可变字符序列 StringBuffer 与 StringBuilder

当需要频繁修改字符串内容时，`String` 的不可变性会导致大量临时对象的产生，效率较低。此时应使用 `StringBuffer` 或 `StringBuilder`。

### 2.1 StringBuffer 与 StringBuilder 的核心区别

-   **`java.lang.StringBuffer`**：
    -   可变的字符序列。
    -   **线程安全**：其公开方法大多用 `synchronized` 修饰，适用于多线程环境。
    -   效率相对较低(由于同步开销)。
    -   底层使用 `char[]` 存储(JDK 8)。
-   **`java.lang.StringBuilder`**：
    -   可变的字符序列。
    -   **线程不安全**：没有同步开销，适用于单线程环境。
    -   效率相对较高。
    -   JDK 1.5 引入。
    -   底层使用 `char[]` 存储(JDK 8)。
-   两者都继承自 `AbstractStringBuilder`，API 非常相似。

### 2.2 StringBuilder/StringBuffer 的常用 API

(以 `StringBuilder` 为例，`StringBuffer` 具有相同或类似方法)

| 方法签名                                                | 描述                                                                 | 返回类型        |
| :------------------------------------------------------ | :------------------------------------------------------------------- | :-------------- |
| `StringBuilder append(X xx)`                            | 追加各种类型 `xx` 的字符串表示到末尾。                               | `StringBuilder` |
| `StringBuilder insert(int offset, X xx)`                | 在指定偏移量 `offset` 处插入各种类型 `xx` 的字符串表示。               | `StringBuilder` |
| `StringBuilder delete(int start, int end)`              | 删除从 `start` 到 `end-1` 的字符。                                     | `StringBuilder` |
| `StringBuilder deleteCharAt(int index)`                 | 删除指定索引 `index` 处的字符。                                      | `StringBuilder` |
| `StringBuilder replace(int start, int end, String str)` | 用 `str` 替换从 `start` 到 `end-1` 的字符。                            | `StringBuilder` |
| `StringBuilder reverse()`                               | 反转字符序列。                                                       | `StringBuilder` |
| `void setCharAt(int index, char ch)`                    | 将指定索引 `index` 处的字符设置为 `ch`。                               | `void`          |
| `char charAt(int index)`                                | 返回指定索引 `index` 处的字符。                                      | `char`          |
| `int length()`                                          | 返回当前字符序列的长度。                                             | `int`           |
| `int capacity()`                                        | 返回当前容量。                                                       | `int`           |
| `void ensureCapacity(int minimumCapacity)`              | 确保容量至少等于指定的最小值。                                       | `void`          |
| `void trimToSize()`                                     | 尝试减少用于字符序列的存储空间。                                     | `void`          |
| `String substring(int start)`                           | 返回从 `start` 到末尾的子字符串 (作为新的 `String` 对象)。             | `String`        |
| `String substring(int start, int end)`                  | 返回从 `start` 到 `end-1` 的子字符串 (作为新的 `String` 对象)。        | `String`        |
| `String toString()`                                     | 返回此序列中数据的字符串表示形式 (创建新的 `String` 对象)。          | `String`        |
| `void setLength(int newLength)`                         | 设置字符序列的长度。若 `newLength` 小于当前长度则截断，大于则用空字符 `\0` 填充。 | `void`          |

-   **方法链操作**：`append`, `insert`, `delete`, `replace`, `reverse` 等返回自身引用的方法支持链式调用。
-   **自动扩容**：当添加的字符超出当前内部数组容量时，会自动进行扩容。

```java
// StringBuilder 示例
StringBuilder sb = new StringBuilder("OS");
sb.append("China").insert(2, "My"); // "OSMyChina"
System.out.println(sb.toString()); // 输出 "OSMyChina"
sb.delete(2, 4); // "OSChina"
System.out.println(sb.reverse().toString()); // "anihCSO"
```

### 2.3 效率对比

在大量字符串拼接操作时，性能排序：
`StringBuilder` > `StringBuffer` >> `String` (使用 `+` 或 `concat`)

-   **选择建议**：
    -   单线程环境，追求效率：优先使用 `StringBuilder`。
    -   多线程环境，共享数据且需保证线程安全：使用 `StringBuffer`。
    -   字符串内容基本不变或拼接次数少：使用 `String` 更简洁。

### 2.4 注意点

-   `StringBuffer sb = new StringBuffer(null);` 会在构造时抛出 `NullPointerException`，因为其内部会尝试访问 `null` 引用(如调用 `null.length()`)。
-   `sb.append(null);` 对于 `StringBuffer` 和 `StringBuilder`，会追加字符串 `"null"`。
    ```java
    StringBuffer sb = new StringBuffer();
    sb.append((String)null); // 追加 "null"
    System.out.println(sb.length()); // 4
    System.out.println(sb.toString()); // "null"
    
    // StringBuffer sb1 = new StringBuffer((String)null); // 会抛出 NullPointerException
    ```
