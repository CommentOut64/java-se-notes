### 1.2 java.util.Date

**注意事项：**

-   月份从0开始：1月=0 (`Calendar.JANUARY`)，12月=11 (`Calendar.DECEMBER`)。
-   星期从1开始：周日=1 (`Calendar.SUNDAY`)，...，周六=7 (`Calendar.SATURDAY`)。

```java
// 获取当前时间的Calendar实例
Calendar calendar = Calendar.getInstance();

// 获取年月日时分秒
int year = calendar.get(Calendar.YEAR);
int month = calendar.get(Calendar.MONTH) + 1; // 月份需要+1才能得到实际月份
int day = calendar.get(Calendar.DAY_OF_MONTH);
int hour = calendar.get(Calendar.HOUR_OF_DAY);
int minute = calendar.get(Calendar.MINUTE);
int second = calendar.get(Calendar.SECOND);

System.out.println(year + "-" + month + "-" + day + " " + hour + ":" + minute + ":" + second);

// 设置日期为2025年10月1日
calendar.set(Calendar.YEAR, 2025);
calendar.set(Calendar.MONTH, Calendar.OCTOBER); // 或者 calendar.set(Calendar.MONTH, 9);
calendar.set(Calendar.DAY_OF_MONTH, 1);
System.out.println("设置后日期：" + calendar.getTime());

// 当前日期增加5天
calendar.add(Calendar.DAY_OF_MONTH, 5);
System.out.println("增加5天后：" + calendar.getTime());

// 获取特定时区的Calendar
Calendar tokyoCalendar = Calendar.getInstance(java.util.TimeZone.getTimeZone("Asia/Tokyo"));
System.out.println("东京时间：" + tokyoCalendar.get(Calendar.HOUR_OF_DAY) + ":" + tokyoCalendar.get(Calendar.MINUTE));
```

## 2. JDK8 新的日期时间API

JDK8引入全新的`java.time` API，解决了旧API的问题：

-   **不可变性**：新API的日期时间对象都是不可变的。
-   **无偏移性**：年份、月份都从正常值开始 (月份1-12)。
-   **线程安全**：不可变对象天然线程安全。
-   **更好的设计**：清晰的API分工，更易于使用。

### 2.1 本地日期时间：LocalDate、LocalTime、LocalDateTime

```java
LocalDateTime currentDateTime = LocalDateTime.now();

System.out.println("当前时间: " + currentTime);
System.out.println("当前日期时间: " + currentDateTime);

// 创建指定日期时间
LocalDate specificDate = LocalDate.of(2025, 10, 1); // 2025年10月1日
LocalTime specificTime = LocalTime.of(14, 30, 15); // 14:30:15
LocalDateTime specificDateTime = LocalDateTime.of(specificDate, specificTime);
// 或者 LocalDateTime.of(2025, java.time.Month.OCTOBER, 1, 14, 30, 15);

System.out.println("特定日期: " + specificDate);
System.out.println("特定时间: " + specificTime);
System.out.println("特定日期时间: " + specificDateTime);

// 日期时间操作
LocalDate nextWeek = today.plusWeeks(1);
LocalTime earlierTime = currentTime.minusHours(2);
LocalDateTime futureDateTime = currentDateTime.plus(java.time.Period.ofMonths(3)).plus(java.time.Duration.ofMinutes(90));

System.out.println("下周同日: " + nextWeek);
System.out.println("两小时前: " + earlierTime);
System.out.println("三个月零90分钟后: " + futureDateTime);

// 获取字段
System.out.println(specificDate.getDayOfWeek()); // 输出星期几
System.out.println(currentDateTime.getMonthValue()); // 输出月份数字

// 格式化

System.out.println("格式化后: " + currentDateTime.format(formatter));
```

### 2.2 瞬时：Instant

表示时间线上的一个瞬时点，通常用于时间戳，精确到纳秒。内部表示为自1970-01-01T00:00:00Z以来的秒数和纳秒数。

| 方法 (常用示例)                                          | 功能描述                                                    | 参数说明 (常用示例)                                                                                   |
| :------------------------------------------------------- | :---------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| `static Instant now()`                                   | 获取当前时刻 (UTC) 的Instant                                | -                                                                                                     |
| `static Instant now(Clock clock)`                        | 从指定时钟获取当前时刻的Instant                             | `clock` (可选)：指定的时钟                                                                              |
| `static Instant ofEpochMilli(long epochMilli)`           | 根据自1970-01-01T00:00:00Z以来的毫秒数创建Instant           | `epochMilli`：毫秒数                                                                                  |
| `static Instant ofEpochSecond(long epochSecond)`         | 根据自1970-01-01T00:00:00Z以来的秒数创建Instant             | `epochSecond`：秒数                                                                                   |
| `static Instant ofEpochSecond(long epochSecond, long nanoAdjustment)` | 根据秒数和纳秒调整创建Instant                               | `epochSecond`：秒数<br>`nanoAdjustment` (可选)：纳秒调整值 (0-999,999,999)                               |
| `long toEpochMilli()`                                    | 将此Instant转换为自1970-01-01T00:00:00Z以来的毫秒数         | -                                                                                                     |
| `long getEpochSecond()`                                  | 获取自1970-01-01T00:00:00Z以来的秒数部分                     | -                                                                                                     |
| `int getNano()`                                          | 获取纳秒部分 (0-999,999,999)                                | -                                                                                                     |
| `OffsetDateTime atOffset(ZoneOffset offset)`             | 结合时区偏移量创建一个 `OffsetDateTime` 对象                  | `offset`：时区偏移量 (如 `ZoneOffset.ofHours(8)`)                                                      |
| `ZonedDateTime atZone(ZoneId zone)`                      | 结合时区ID创建一个 `ZonedDateTime` 对象                       | `zone`：时区ID (如 `ZoneId.of("Asia/Shanghai")`)                                                      |
| `Instant plusSeconds(long secondsToAdd)` / `plusMillis(...)` / `plusNanos(...)` | 增加秒/毫秒/纳秒并返回新Instant                             | `secondsToAdd` / `millisToAdd` / `nanosToAdd`：增加的数量                                             |
| `Instant plus(TemporalAmount amount)`                    | 增加一个时间量 (如 `Duration`) 并返回新Instant                | `amount`：时间量对象                                                                                  |
| `Instant minusSeconds(long secondsToSubtract)` / `minusMillis(...)` / `minusNanos(...)` | 减少秒/毫秒/纳秒并返回新Instant                             | `secondsToSubtract` / `millisToSubtract` / `nanosToSubtract`：减少的数量                            |
| `Instant minus(TemporalAmount amount)`                   | 减少一个时间量并返回新Instant                                 | `amount`：时间量对象                                                                                  |
| `boolean isBefore(Instant otherInstant)` / `isAfter(...)`  | 比较两个Instant的先后                                       | `otherInstant`：要比较的Instant                                                                       |

```java
Instant currentInstant = Instant.now();
System.out.println("当前UTC瞬时: " + currentInstant);

// 转换为毫秒时间戳
long epochMillis = currentInstant.toEpochMilli();
System.out.println("毫秒时间戳: " + epochMillis);

// 从毫秒时间戳创建Instant
Instant fromMillis = Instant.ofEpochMilli(epochMillis);
System.out.println("从毫秒创建: " + fromMillis);

// 获取秒和纳秒部分
long epochSeconds = currentInstant.getEpochSecond();
int nanoPart = currentInstant.getNano();
System.out.println("秒部分: " + epochSeconds + ", 纳秒部分: " + nanoPart);

// 转换为特定时区的ZonedDateTime
ZonedDateTime beijingTime = currentInstant.atZone(ZoneId.of("Asia/Shanghai"));
System.out.println("北京时间: " + beijingTime);

// 时间运算
Instant later = currentInstant.plusSeconds(3600); // 1小时后
System.out.println("1小时后: " + later);
```

### 2.3 日期时间格式化：DateTimeFormatter

| :------------------------------------------------------- | :---------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `static DateTimeFormatter ofPattern(String pattern)`     | 使用指定的模式字符串创建格式化器                            | `pattern`：日期时间格式模式 (如 "yyyy-MM-dd HH:mm:ss")                                                                                                                                                             |
| `static DateTimeFormatter ofPattern(String pattern, Locale locale)` | 使用指定的模式和地区创建格式化器                            | `pattern`：模式字符串<br>`locale` (可选)：地区设置，影响月份、星期等的语言和格式                                                                                                                                      |
| `static DateTimeFormatter ofLocalizedDate(FormatStyle dateStyle)` | 创建本地化日期格式化器                                      | `dateStyle`：日期格式样式 (如 `FormatStyle.SHORT`, `FormatStyle.MEDIUM`, `FormatStyle.LONG`, `FormatStyle.FULL`)                                                                                                   |
| `static DateTimeFormatter ofLocalizedTime(FormatStyle timeStyle)` | 创建本地化时间格式化器                                      | `timeStyle`：时间格式样式                                                                                                                                                                                            |
| `static DateTimeFormatter ofLocalizedDateTime(FormatStyle dateTimeStyle)` | 创建本地化日期时间格式化器                                  | `dateTimeStyle`：日期时间格式样式                                                                                                                                                                                    |
| `static DateTimeFormatter ofLocalizedDateTime(FormatStyle dateStyle, FormatStyle timeStyle)` | 创建本地化日期时间格式化器 (分别指定日期和时间样式)         | `dateStyle` (可选)：日期格式样式<br>`timeStyle` (可选)：时间格式样式                                                                                                                                                     |
| `String format(TemporalAccessor temporal)`               | 将给定的日期时间对象格式化为字符串                          | `temporal`：要格式化的日期时间对象 (如 `LocalDate`, `LocalDateTime`, `ZonedDateTime`)                                                                                                                                |
| `TemporalAccessor parse(CharSequence text)`              | 将文本字符串解析为通用的日期时间对象 (通常需进一步转换)       | `text`：要解析的字符串                                                                                                                                                                                             |
| `T parse(CharSequence text, TemporalQuery<T> query)`     | 将文本字符串解析为特定类型的日期时间对象                      | `text`：要解析的字符串<br>`query`：类型查询 (如 `LocalDate::from`, `LocalDateTime::from`)                                                                                                                            |
| `DateTimeFormatter withLocale(Locale locale)`            | 返回具有新区域设置的此格式化程序副本                        | `locale` (可选)：新的地区设置                                                                                                                                                                                          |
| `DateTimeFormatter withZone(ZoneId zone)`                | 返回具有新时区ID的此格式化程序副本 (主要影响格式化带时区信息的对象) | `zone` (可选)：新的时区ID                                                                                                                                                                                            |

**预定义格式化器常量：** `DateTimeFormatter.ISO_LOCAL_DATE`, `DateTimeFormatter.ISO_LOCAL_TIME`, `DateTimeFormatter.ISO_LOCAL_DATE_TIME`, `DateTimeFormatter.ISO_OFFSET_DATE_TIME`, `DateTimeFormatter.ISO_ZONED_DATE_TIME`, `DateTimeFormatter.RFC_1123_DATE_TIME` 等。

```java
LocalDateTime now = LocalDateTime.now();

// 自定义格式
DateTimeFormatter customFormatter = DateTimeFormatter.ofPattern("yyyy年MM月dd日 HH:mm:ss E");
String formattedCustom = now.format(customFormatter);
System.out.println("自定义格式化: " + formattedCustom);

// 解析
String dateTimeStr = "2025年10月01日 15:30:00 星期三";
try {
    LocalDateTime parsedDateTime = LocalDateTime.parse(dateTimeStr, customFormatter);
    System.out.println("解析后: " + parsedDateTime);
} catch (java.time.format.DateTimeParseException e) {
    System.err.println("解析错误: " + e.getMessage());
}


// 使用预定义ISO格式
DateTimeFormatter isoFormatter = DateTimeFormatter.ISO_LOCAL_DATE_TIME;
String formattedIso = now.format(isoFormatter);
System.out.println("ISO格式化: " + formattedIso);
LocalDateTime parsedIso = LocalDateTime.parse(formattedIso, isoFormatter); // 或者 LocalDateTime.parse(formattedIso)
System.out.println("ISO解析后: " + parsedIso);

// 本地化格式 (例如：美国长日期格式)
DateTimeFormatter localizedFormatter = DateTimeFormatter.ofLocalizedDate(FormatStyle.LONG)
                                                     .withLocale(java.util.Locale.US);
System.out.println("美国长日期格式: " + LocalDate.now().format(localizedFormatter));
```

#### 时间间隔计算

| 类         | 功能描述                                                    | 常用方法 (示例)                                                                                                                                                                                                                               | 适用对象                                                                 |
| :--------- | :---------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------- |
| `Duration` | 表示以秒和纳秒为单位的时间量，用于精确测量时间差。不可变。      | `static Duration between(Temporal startInclusive, Temporal endExclusive)`<br>`static Duration ofDays(long days)` / `ofHours(...)` / `ofSeconds(...)`<br>`long toDays()` / `toHours()` / `toMinutes()` / `getSeconds()` / `toMillis()` / `toNanos()`<br>`int getNano()` 获取纳秒部分 | `Instant`, `LocalTime`, `LocalDateTime` (通常用于基于时间的操作)         |
| `Period`   | 表示以年、月、日为单位的日期量，用于测量日期差。不可变。        | `static Period between(LocalDate startDateInclusive, LocalDate endDateExclusive)`<br>`static Period ofYears(int years)` / `ofMonths(...)` / `ofDays(...)`<br>`int getYears()` / `getMonths()` / `getDays()`<br>`long toTotalMonths()` 获取总月数 | `LocalDate` (通常用于基于日期的操作)                                     |

```java
// 时区处理示例
ZoneId shanghaiZone = ZoneId.of("Asia/Shanghai");
ZonedDateTime shanghaiNow = ZonedDateTime.now(shanghaiZone);
System.out.println("上海当前时间: " + shanghaiNow);

ZonedDateTime newYorkNow = shanghaiNow.withZoneSameInstant(ZoneId.of("America/New_York"));
System.out.println("纽约对应时间: " + newYorkNow);

// 时间间隔示例
LocalDate startDate = LocalDate.of(2025, 1, 15);
LocalDate endDate = LocalDate.of(2025, 3, 10);
Period periodBetween = Period.between(startDate, endDate);
System.out.println("日期差: " + periodBetween.getMonths() + "月 " + periodBetween.getDays() + "天");

LocalTime startTime = LocalTime.of(9, 0, 0);
LocalTime endTime = LocalTime.of(17, 30, 0);
Duration durationBetween = Duration.between(startTime, endTime);
System.out.println("时间差: " + durationBetween.toHours() + "小时 " + durationBetween.toMinutesPart() + "分钟"); // toMinutesPart需要JDK 9+
// JDK 8中可以这样获取分钟部分：durationBetween.toMinutes() % 60
```

### 2.5 与传统API的转换

| 新API 类                               | 转换为遗留类方法                  | 遗留类                                | 从遗留类转换方法                     |
| :-------------------------------------- | :-------------------------------- | :------------------------------------ | :----------------------------------- |
| `java.time.Instant`                   | `Date.from(instant)`              | `java.util.Date`                    | `date.toInstant()`                   |
| `java.time.Instant`                   | `Timestamp.from(instant)`         | `java.sql.Timestamp`                | `timestamp.toInstant()`              |
| `java.time.ZonedDateTime`             | `GregorianCalendar.from(zonedDateTime)` | `java.util.GregorianCalendar`       | `gregorianCalendar.toZonedDateTime()` |
| `java.time.LocalDate`                 | `Date.valueOf(localDate)`         | `java.sql.Date`                     | `sqlDate.toLocalDate()`              |
| `java.time.LocalTime`                 | `Time.valueOf(localTime)`         | `java.sql.Time`                     | `sqlTime.toLocalTime()`              |
| `java.time.LocalDateTime`             | `Timestamp.valueOf(localDateTime)`| `java.sql.Timestamp`                | `sqlTimestamp.toLocalDateTime()`     |
| `java.time.ZoneId`                    | `TimeZone.getTimeZone(zoneId)`    | `java.util.TimeZone`                | `timeZone.toZoneId()`                |
| `java.time.format.DateTimeFormatter`  | `formatter.toFormat()`            | `java.text.Format` (父类)           | (无直接方法从`DateFormat`转换)     |

```java
// Instant <-> java.util.Date
Instant nowInstant = Instant.now();
Date nowDate = Date.from(nowInstant);
Instant backToInstant = nowDate.toInstant();
System.out.println("Date from Instant: " + nowDate);
System.out.println("Instant from Date: " + backToInstant);

// LocalDate <-> java.sql.Date
LocalDate todayLocalDate = LocalDate.now();
java.sql.Date todaySqlDate = java.sql.Date.valueOf(todayLocalDate);
LocalDate backToLocalDate = todaySqlDate.toLocalDate();
System.out.println("java.sql.Date from LocalDate: " + todaySqlDate);
System.out.println("LocalDate from java.sql.Date: " + backToLocalDate);

// ZoneId <-> java.util.TimeZone
ZoneId systemZoneId = ZoneId.systemDefault();
java.util.TimeZone systemTimeZone = java.util.TimeZone.getTimeZone(systemZoneId);
ZoneId backToZoneId = systemTimeZone.toZoneId();
System.out.println("TimeZone from ZoneId: " + systemTimeZone.getID());
System.out.println("ZoneId from TimeZone: " + backToZoneId);
```
