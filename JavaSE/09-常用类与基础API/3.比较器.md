## 1. Java 比较器概述

在 Java 中，基本数据类型（除 `boolean` 外）可以直接使用比较运算符（如 `>`、`<`、`==`）比较大小。但引用数据类型不能直接使用这些运算符比较，需要特定的机制来实现对象间的比较和排序。Java 提供了两种主要的比较方式：

*   **自然排序**：通过实现 `java.lang.Comparable` 接口。
*   **定制排序**：通过实现 `java.util.Comparator` 接口。

这两种方式主要用于对象数组或集合的排序。

## 2. 自然排序：`java.lang.Comparable` 接口

`Comparable` 接口强行对实现它的每个类的对象进行整体排序，这种排序被称为类的**自然排序**。通常，一个类如果具有明显的、主要的排序逻辑，可以实现此接口。

### 2.1. 核心方法

实现 `Comparable` 接口的类**必须**实现其核心方法：

| 方法名                                   | 参数                        | 返回值                                                       | 说明                                                         |
| :--------------------------------------- | :-------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `int compareTo(T o)` (使用泛型后)        | `T o` (待比较的对象)        | `int` <br/> - **正整数**：当前对象大于参数对象 `o` <br/> - **负整数**：当前对象小于参数对象 `o` <br/> - **零**：当前对象等于参数对象 `o` | 定义当前对象与指定对象的比较规则。                           |
| `int compareTo(Object obj)` (未使用泛型) | `Object obj` (待比较的对象) | 同上                                                         | 需要在方法内部进行类型检查和强制类型转换，推荐使用泛型版本以获得类型安全和代码简洁性。 |

### 2.2. 使用与特性

*   实现了 `Comparable` 接口的对象列表（如 `List<T>`）或数组（如 `T[]`）可以通过 `Collections.sort()` 或 `Arrays.sort()` 方法进行自动排序，**无需额外指定比较器**。
*   **与 `equals` 的一致性**：如果类 `C` 的自然排序满足“当且仅当 `e1.compareTo(e2) == 0` 与 `e1.equals(e2)` 具有相同的布尔值”时，则称其自然排序与 `equals` 方法一致。虽然不是强制要求，但强烈建议使自然排序与 `equals` 方法保持一致，以避免在某些集合（如 `TreeSet`、`TreeMap`）中出现意外行为。
*   在实例方法（包括 `compareTo`）中，`this` 关键字始终指向调用该方法的那个对象，也就是“当前对象实例”。
*   **常见 JDK 类的实现**（默认升序）：
    *   `String`：按字符串中字符的 Unicode 值逐位比较。
    *   `Character`：按字符的 Unicode 值比较。
    *   数值类型包装类（`Integer`、`Double` 等）、`BigInteger`、`BigDecimal`：按数值大小比较。
    *   `Boolean`：`true` 大于 `false`。
    *   日期时间类（`Date`、`LocalDateTime` 等）：较晚的日期时间大于较早的。

### 2.3. 代码示例

以商品类 `Goods` 为例，实现按价格进行自然排序（升序）。

```java
class Goods implements Comparable<Goods> {
    private String name;
    private double price;

    public Goods(String name, double price) {
        this.name = name;
        this.price = price;
    }

    public String getName() {
        return name;
    }

    public double getPrice() {
        return price;
    }

    @Override
    public String toString() {
        return "Goods{name='" + name + "', price=" + price + "}";
    }

    // 按价格升序排序
    @Override
    public int compareTo(Goods other) {
        if (this.price > other.price) {
            return 1;
        } else if (this.price < other.price) {
            return -1;
        }
        return 0;
    }
    // 或者更简洁的写法 (适用于JDK 7+):
    @Override
    public int compareTo(Goods other) {
        // 使用 Double.compare 简洁且安全地比较两个 double 值
        return Double.compare(this.price, other.price);
    }
}
```

测试代码：

    }

使用自定义比较器：

```java
import java.util.*;

// 假设已有 Goods 类，实现了 Comparable<Goods>，并含有 price、name 等属性
public class Goods {
    private String name;
    private double price;

    public Goods(String name, double price) {
        this.name  = name;
        this.price = price;
    }

    public String getName()  { return name; }
    public double getPrice(){ return price; }

    @Override
    public String toString() {
        return name + ": $" + price;
    }
}

public class Main {
    public static void main(String[] args) {
        List<Goods> list = Arrays.asList(
            new Goods("苹果",  5.0),
            new Goods("香蕉",  3.0),
            new Goods("葡萄", 10.0)
        );

        // ► 方法一：使用匿名内部类
        Collections.sort(list, new Comparator<Goods>() {
            @Override
            public int compare(Goods g1, Goods g2) {
                // 降序：g2 - g1
                return Double.compare(g2.getPrice(), g1.getPrice());
            }
        });
        System.out.println("降序排序（匿名类）: " + list);

        // ► 方法二：使用 Java 8 Lambda 表达式
        list = Arrays.asList(
            new Goods("苹果",  5.0),
            new Goods("香蕉",  3.0),
            new Goods("葡萄", 10.0)
        );
        Collections.sort(list, (g1, g2) -> Double.compare(g2.getPrice(), g1.getPrice()));
        System.out.println("降序排序（Lambda）: " + list);

        // ► 方法三：List 接口的默认 sort 方法
        list = Arrays.asList(
            new Goods("苹果",  5.0),
            new Goods("香蕉",  3.0),
            new Goods("葡萄", 10.0)
        );
        list.sort(Comparator.comparingDouble(Goods::getPrice).reversed());
        System.out.println("降序排序（comparingDouble + reversed）: " + list);

        // ► 对数组进行自定义排序
        Goods[] array = {
            new Goods("苹果",  5.0),
            new Goods("香蕉",  3.0),
            new Goods("葡萄", 10.0)
        };
        Arrays.sort(array, Comparator.comparing(Goods::getName));
        System.out.println("按名称升序排序（数组）: " + Arrays.toString(array));
    }
}
```

## 3. 定制排序：`java.util.Comparator` 接口

当以下情况出现时，`Comparator` 接口提供了更灵活的排序解决方案：

*   元素的类型没有实现 `java.lang.Comparable` 接口，且不方便修改其源代码（例如，第三方库的类）。
*   类已经实现了 `Comparable` 接口（定义了自然排序），但希望在特定场景下使用不同的排序规则，而又不想修改原有的自然排序逻辑。

`Comparator` 接口用于定义独立于对象自身的比较逻辑。

### 3.1. 核心方法

实现 `Comparator` 接口需要重写其核心方法：

| 方法名                                           | 参数                                                    | 返回值                                                       | 说明                                     |
| :----------------------------------------------- | :------------------------------------------------------ | :----------------------------------------------------------- | :--------------------------------------- |
| `int compare(T o1, T o2)` (使用泛型后)           | `T o1` (第一个待比较对象)<br/>`T o2` (第二个待比较对象) | `int` <br/> - **正整数**：`o1` 大于 `o2` <br/> - **负整数**：`o1` 小于 `o2` <br/> - **零**：`o1` 等于 `o2` | 定义对象 `o1` 和 `o2` 的比较规则。       |
| `int compare(Object o1, Object o2)` (未使用泛型) | `Object o1`<br/>`Object o2`                             | 同上                                                         | 需要在方法内部进行类型检查和强制类型转换 |

### 3.2. 使用与特性

*   可以将 `Comparator` 的实例传递给 `Collections.sort()` 或 `Arrays.sort()` 方法的重载版本，从而实现定制排序。
*   `Comparator` 的实现通常是创建一个单独的类，或者使用匿名内部类，在 Java 8 及以上版本中，更推荐使用 Lambda 表达式来创建 `Comparator` 实例，代码更为简洁。

### 3.3. 代码示例

以 `Student` 类为例，演示如何使用 `Comparator` 进行定制排序。

```java
class Student {
    private int id;
    private String name;
    private int score;
    private int age;

    public Student(int id, String name, int score, int age) {
        this.id = id;
        this.name = name;
        this.score = score;
        this.age = age;
    }

    // Getters
    public int getId() { return id; }
    public String getName() { return name; }
    public int getScore() { return score; }
    public int getAge() { return age; }

    @Override
    public String toString() {
        return "Student{id=" + id + ", name='" + name + "', score=" + score + ", age=" + age + "}";
    }
}
```

#### 3.3.1. 使用单独的类实现 Comparator

按分数升序排序，如果分数相同，则按学号升序排序。

```java
import java.util.Comparator;

class StudentScoreComparator implements Comparator<Student> {
    @Override
    public int compare(Student s1, Student s2) {
        if (s1.getScore() != s2.getScore()) {
            return s1.getScore() - s2.getScore(); // 分数升序
        } else {
            return s1.getId() - s2.getId(); // 分数相同，按学号升序
        }
    }
}
```

#### 3.3.2. 使用 Lambda 表达式实现 Comparator (Java 8+)

按年龄降序排序。

```java
import java.util.Arrays;
import java.util.Comparator;

public class ComparatorTest {
    public static void main(String[] args) {
        Student[] students = new Student[4];
        students[0] = new Student(3, "张三", 90, 23);
        students[1] = new Student(1, "熊大", 100, 22);
        students[2] = new Student(5, "王五", 75, 25);
        students[3] = new Student(2, "熊二", 85, 18);

        System.out.println("原始顺序：" + Arrays.toString(students));

        // 使用 StudentScoreComparator 进行排序 (分数升序，学号升序)
        Arrays.sort(students, new StudentScoreComparator());
        System.out.println("按分数、学号升序：" + Arrays.toString(students));

        // 重置数组顺序以便演示下一种排序
        students[0] = new Student(3, "张三", 90, 23);
        students[1] = new Student(1, "熊大", 100, 22);
        students[2] = new Student(5, "王五", 75, 25);
        students[3] = new Student(2, "熊二", 85, 18);

        // 使用 Lambda 表达式按年龄降序排序
        Comparator<Student> ageDescComparator = (s1, s2) -> s2.getAge() - s1.getAge();
        Arrays.sort(students, ageDescComparator);
        System.out.println("按年龄降序：" + Arrays.toString(students));
        
        // 使用 Comparator.comparing
        // 按姓名升序
        Arrays.sort(students, Comparator.comparing(Student::getName));
        System.out.println("按姓名升序：" + Arrays.toString(students));

        // 多级排序：先按分数降序，再按年龄升序
        Comparator<Student> multiComparator = Comparator.comparing(Student::getScore, Comparator.reverseOrder()) // 分数降序
                                                        .thenComparingInt(Student::getAge);                   // 年龄升序
        Arrays.sort(students, multiComparator);
        System.out.println("按分数降序再按年龄升序：" + Arrays.toString(students));
    }
}
```

## 4. `Comparable` 与 `Comparator` 对比

| 特性         | `java.lang.Comparable`                               | `java.util.Comparator`                                       |
| :----------- | :--------------------------------------------------- | :----------------------------------------------------------- |
| **定义位置** | 在需要排序的类内部实现接口。                         | 通常是独立的类，或作为匿名内部类/Lambda 表达式实现。         |
| **侵入性**   | 对原有类有侵入性（需要修改类定义）。                 | 对原有类无侵入性。                                           |
| **排序方式** | 定义对象的“自然排序”规则，一种排序逻辑。             | 定义“定制排序”或“临时排序”规则，可以有多种排序逻辑。         |
| **使用场景** | 当类有主要的、固定的排序需求时。                     | 当类没有实现 `Comparable`、无法修改类源码，或需要多种不同排序规则时。 |
| **调用方式** | `Arrays.sort(objArray)`<br/>`Collections.sort(list)` | `Arrays.sort(objArray, comparator)`<br/>`Collections.sort(list, comparator)` |
| **灵活性**   | 较低，一种对象通常只有一种自然排序。                 | 较高，可以为同一种对象定义任意多种比较器。                   |
| **泛型使用** | `class MyClass implements Comparable<MyClass>`       | `class MyComparator implements Comparator<MyClass>` 或 `Comparator<MyClass> comp = ...;` |

总结来说，`Comparable` 是“内比较器”，定义了对象的默认比较方式；`Comparator` 是“外比较器”，用于在需要时提供特定的比较方式。在实际开发中，两者经常结合使用。
