## 2.1 `java.lang.Math` 类

`Math` 类包含用于执行基本数学运算的方法，如指数、对数、平方根和三角函数等。

-   `Math` 类中的所有方法都是静态的 (`static`)，可以直接通过类名调用。
-   它有一个私有构造函数，因此不能被实例化。
-   它还定义了两个 `double` 类型的常量：`PI` (圆周率 π) 和 `E` (自然对数的底数 e)。

### 2.1.1 常用成员方法

| 方法签名                                 | 功能描述                                                     | 参数说明                       |
| :--------------------------------------- | :----------------------------------------------------------- | :----------------------------- |
| `static double abs(double a)`            | 返回 `double` 值的绝对值。 (有 `float`, `int`, `long` 的重载版本) | `a`：一个数值。                |
| `static double ceil(double a)`           | 返回大于或等于参数的最小整数值 (向上取整)。                  | `a`：一个 `double` 值。        |
| `static double floor(double a)`          | 返回小于或等于参数的最大整数值 (向下取整)。                  | `a`：一个 `double` 值。        |
| `static long round(double a)`            | 返回最接近参数的 `long` 值 (四舍五入)。                      | `a`：一个 `double` 值。        |
| `static int round(float a)`              | 返回最接近参数的 `int` 值 (四舍五入)。                       | `a`：一个 `float` 值。         |
| `static double pow(double a, double b)`  | 返回第一个参数的第二个参数次幂的值 (a<sup>b</sup>)。         | `a`：底数。<br>`b`：指数。     |
| `static double sqrt(double a)`           | 返回 `double` 值的正平方根。                                 | `a`：一个非负 `double` 值。    |
| `static double random()`                 | 返回一个大于等于 0.0 且小于 1.0 的伪随机 `double` 值。       | -                              |
| `static double max(double a, double b)`  | 返回两个 `double` 值中较大的一个。 (有 `float`, `int`, `long` 的重载版本) | `a`, `b`：两个数值。           |
| `static double min(double a, double b)`  | 返回两个 `double` 值中较小的一个。 (有 `float`, `int`, `long` 的重载版本) | `a`, `b`：两个数值。           |
| `static double sin(double a)`            | 返回角的三角正弦。                                           | `a`：以弧度表示的角度。        |
| `static double cos(double a)`            | 返回角的三角余弦。                                           | `a`：以弧度表示的角度。        |
| `static double tan(double a)`            | 返回角的三角正切。                                           | `a`：以弧度表示的角度。        |
| `static double toRadians(double angdeg)` | 将以度为单位测量的角度转换为以弧度为单位测量的近似等效角度。 | `angdeg`：以度为单位的角度。   |
| `static double toDegrees(double angrad)` | 将以弧度为单位测量的角度转换为以度为单位测量的近似等效角度。 | `angrad`：以弧度为单位的角度。 |
| `static double log(double a)`            | 返回 `double` 值的自然对数 (以 e 为底)。                     | `a`：一个正 `double` 值。      |
| `static double log10(double a)`          | 返回 `double` 值的以 10 为底的对数。                         | `a`：一个正 `double` 值。      |
| `static double exp(double a)`            | 返回欧拉数 e 的 `double` 次幂 (e<sup>a</sup>)。              | `a`：指数。                    |

```java
public class MathDemo {
    public static void main(String[] args) {
        System.out.println("PI 常量: " + Math.PI);
        System.out.println("E 常量: " + Math.E);

        System.out.println("|-5.5| = " + Math.abs(-5.5));
        System.out.println("ceil(3.14) = " + Math.ceil(3.14));   // 4.0
        System.out.println("floor(3.14) = " + Math.floor(3.14)); // 3.0
        System.out.println("round(3.5) = " + Math.round(3.5));   // 4
        System.out.println("round(3.4) = " + Math.round(3.4));   // 3
        System.out.println("2^3 = " + Math.pow(2, 3));           // 8.0
        System.out.println("sqrt(16) = " + Math.sqrt(16));       // 4.0
        System.out.println("随机数 [0.0, 1.0): " + Math.random());
        System.out.println("max(10, 20) = " + Math.max(10, 20));
        System.out.println("sin(PI/2) = " + Math.sin(Math.PI / 2)); // 1.0
    }
}
```

## 2.2 `java.math.BigInteger` 类

`BigInteger` 类用于表示不可变的任意精度的整数。当整数大小超过 `long` 类型的表示范围时，可以使用此类。

### 2.2.1 常用构造器

| 构造器签名                                 | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `BigInteger(String val)`                   | 将十进制字符串表示形式转换为 `BigInteger`。                  | `val`：整数的字符串表示。                                    |
| `BigInteger(byte[] val)`                   | 将包含 `BigInteger` 的二进制补码表示形式的字节数组转换为 `BigInteger`。 | `val`：字节数组。                                            |
| `BigInteger(int signum, byte[] magnitude)` | 将 `BigInteger` 的符号大小表示形式转换为 `BigInteger`。      | `signum`：数字的符号 (-1 表示负，0 表示零，1 表示正)。<br>`magnitude`：数字大小的 big-endian 字节顺序数组表示。 |

### 2.2.2 常用成员方法

| 方法签名                                          | 功能描述                                                     | 参数说明                                          |
| :------------------------------------------------ | :----------------------------------------------------------- | :------------------------------------------------ |
| `BigInteger add(BigInteger val)`                  | 返回其值为 `(this + val)` 的 `BigInteger`。                  | `val`：要加到此 `BigInteger` 的值。               |
| `BigInteger subtract(BigInteger val)`             | 返回其值为 `(this - val)` 的 `BigInteger`。                  | `val`：要从此 `BigInteger` 减去的值。             |
| `BigInteger multiply(BigInteger val)`             | 返回其值为 `(this * val)` 的 `BigInteger`。                  | `val`：要与此 `BigInteger` 相乘的值。             |
| `BigInteger divide(BigInteger val)`               | 返回其值为 `(this / val)` 的 `BigInteger` (整数除法，舍去小数部分)。 | `val`：此 `BigInteger` 要相除的值。               |
| `BigInteger remainder(BigInteger val)`            | 返回其值为 `(this % val)` 的 `BigInteger`。                  | `val`：此 `BigInteger` 要计算余数的值。           |
| `BigInteger[] divideAndRemainder(BigInteger val)` | 返回一个包含 `(this / val)` 和 `(this % val)` 的两个 `BigInteger` 的数组。 | `val`：除数。                                     |
| `BigInteger pow(int exponent)`                    | 返回其值为 `(this^exponent)` 的 `BigInteger`。               | `exponent`：指数。                                |
| `BigInteger abs()`                                | 返回此 `BigInteger` 的绝对值。                               | -                                                 |
| `BigInteger negate()`                             | 返回其值为 `(-this)` 的 `BigInteger`。                       | -                                                 |
| `int compareTo(BigInteger val)`                   | 将此 `BigInteger` 与指定的 `BigInteger` 进行比较。           | `val`：要比较的 `BigInteger`。 返回 -1, 0, 或 1。 |
| `BigInteger gcd(BigInteger val)`                  | 返回 `abs(this)` 和 `abs(val)` 的最大公约数。                | `val`：与此 `BigInteger` 计算 GCD 的值。          |
| `boolean isProbablePrime(int certainty)`          | 如果此 `BigInteger` 可能为素数，则返回 `true`，否则返回 `false`。 | `certainty`：调用者允许的确定性。值越高，越可靠。 |

```java
import java.math.BigInteger;

public class BigIntegerDemo {
    public static void main(String[] args) {
        BigInteger num1 = new BigInteger("12345678901234567890");
        BigInteger num2 = new BigInteger("98765432109876543210");

        System.out.println("num1: " + num1);
        System.out.println("num2: " + num2);

        System.out.println("和 (add): " + num1.add(num2));
        System.out.println("差 (subtract): " + num2.subtract(num1));
        System.out.println("积 (multiply): " + num1.multiply(new BigInteger("100")));
        System.out.println("商 (divide): " + num2.divide(num1));
        System.out.println("余数 (remainder): " + num2.remainder(num1));
        System.out.println("num1 的 3 次幂 (pow): " + num1.pow(3));
    }
}
```

## 2.3 `java.math.BigDecimal` 类

`BigDecimal` 类用于表示不可变的、任意精度的有符号十进制数。它主要用于需要高精度计算的场景，如商业和金融计算，可以避免 `float` 和 `double` 类型带来的舍入误差。

### 2.3.1 常用构造器

| 构造器签名                                         | 功能描述                                                     | 参数说明                                                     |
| :------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `BigDecimal(String val)`                           | 将 `String` 表示形式转换为 `BigDecimal`。**推荐使用此构造器**以避免 `double` 的精度问题。 | `val`：十进制数的字符串表示。                                |
| `BigDecimal(double val)`                           | 将 `double` 转换为 `BigDecimal`。**不推荐**，因为 `double` 本身可能不精确。 | `val`：一个 `double` 值。例如 `new BigDecimal(0.1)` 并不完全等于 0.1。 |
| `BigDecimal(int val)`                              | 将 `int` 转换为 `BigDecimal`。                               | `val`：一个 `int` 值。                                       |
| `BigDecimal(long val)`                             | 将 `long` 转换为 `BigDecimal`。                              | `val`：一个 `long` 值。                                      |
| `BigDecimal(BigInteger val)`                       | 将 `BigInteger` 未经换算的十进制值转换为 `BigDecimal`。      | `val`：一个 `BigInteger` 值。                                |
| `BigDecimal(BigInteger unscaledVal, int scale)`    | 将 `BigInteger` 的未缩放值和 `int` 标度转换为 `BigDecimal`。 | `unscaledVal`：`BigDecimal` 的未缩放值。<br>`scale`：`BigDecimal` 的标度 (小数点后的位数)。 |
| `BigDecimal(String val, java.math.MathContext mc)` | 使用上下文设置将字符串转换为 `BigDecimal`。                  | `val`：十进制数的字符串表示。<br>`mc` (可选)：上下文设置，指定精度和舍入模式。 |

### 2.3.2 常用成员方法

| 方法签名                                                     | 功能描述                                                     | 参数说明                                                     |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `BigDecimal add(BigDecimal augend)`                          | 返回其值为 `(this + augend)` 的 `BigDecimal`，其标度为 `max(this.scale(), augend.scale())`。 | `augend`：要加到此 `BigDecimal` 的值。                       |
| `BigDecimal subtract(BigDecimal subtrahend)`                 | 返回其值为 `(this - subtrahend)` 的 `BigDecimal`，其标度为 `max(this.scale(), subtrahend.scale())`。 | `subtrahend`：要从此 `BigDecimal` 减去的值。                 |
| `BigDecimal multiply(BigDecimal multiplicand)`               | 返回其值为 `(this * multiplicand)` 的 `BigDecimal`，其标度为 `(this.scale() + multiplicand.scale())`。 | `multiplicand`：要与此 `BigDecimal` 相乘的值。               |
| `BigDecimal divide(BigDecimal divisor)`                      | 返回其值为 `(this / divisor)` 的 `BigDecimal`。如果无法表示准确的商 (例如，无限小数)，则抛出 `ArithmeticException`。 | `divisor`：此 `BigDecimal` 要相除的值。                      |
| `BigDecimal divide(BigDecimal divisor, int scale, RoundingMode roundingMode)` | 返回其值为 `(this / divisor)` 的 `BigDecimal`，其标度为指定标度，并应用指定的舍入模式。 | `divisor`：除数。<br>`scale`：结果的标度 (小数点后的位数)。<br>`roundingMode`：要应用的舍入模式 (来自 `java.math.RoundingMode` 枚举)。 |
| `BigDecimal divide(BigDecimal divisor, RoundingMode roundingMode)` | 返回其值为 `(this / divisor)` 的 `BigDecimal`，其标度为 `this.scale()`，并应用指定的舍入模式。 | `divisor`：除数。<br>`roundingMode`：要应用的舍入模式。      |
| `BigDecimal setScale(int newScale, RoundingMode roundingMode)` | 返回一个 `BigDecimal`，其标度为指定值，其未缩放值通过将此 `BigDecimal` 的未缩放值乘以或除以适当的 10 的幂来确定，以保持其总值。 | `newScale`：要返回的 `BigDecimal` 值的标度。<br>`roundingMode`：要应用的舍入模式。 |
| `BigDecimal abs()`                                           | 返回此 `BigDecimal` 的绝对值。                               | -                                                            |
| `BigDecimal negate()`                                        | 返回其值为 `(-this)` 的 `BigDecimal`。                       | -                                                            |
| `int compareTo(BigDecimal val)`                              | 将此 `BigDecimal` 与指定的 `BigDecimal` 进行比较。           | `val`：要比较的 `BigDecimal`。返回 -1 (小于), 0 (等于), 或 1 (大于)。 |
| `double doubleValue()`                                       | 将此 `BigDecimal` 转换为 `double` (可能损失精度)。           | -                                                            |
| `int intValue()`                                             | 将此 `BigDecimal` 转换为 `int` (可能损失精度并舍去小数部分)。 | -                                                            |

**`java.math.RoundingMode` 枚举常量 (常用)：**

-   `UP`：远离零方向舍入。
-   `DOWN`：向零方向舍入 (截断)。
-   `CEILING`：向正无穷方向舍入。
-   `FLOOR`：向负无穷方向舍入。
-   `HALF_UP`：四舍五入。
-   `HALF_DOWN`：五舍六入。
-   `HALF_EVEN`：银行家舍入法 (向最接近的偶数舍入)。
-   `UNNECESSARY`：断言请求的操作具有精确的结果，因此不需要舍入。如果对产生不精确结果的操作指定此舍入模式，则抛出 `ArithmeticException`。

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

public class BigDecimalDemo {
    public static void main(String[] args) {
        BigDecimal price = new BigDecimal("19.99");
        BigDecimal quantity = new BigDecimal("2.5");
        BigDecimal taxRate = new BigDecimal("0.075");

        BigDecimal subtotal = price.multiply(quantity);
        System.out.println("小计 (Subtotal): " + subtotal); // 49.975

        // 设置精度和舍入模式
        BigDecimal subtotalRounded = subtotal.setScale(2, RoundingMode.HALF_UP);
        System.out.println("四舍五入后的小计: " + subtotalRounded); // 49.98

        BigDecimal tax = subtotalRounded.multiply(taxRate).setScale(2, RoundingMode.HALF_UP);
        System.out.println("税额 (Tax): " + tax); // 3.75

        BigDecimal total = subtotalRounded.add(tax);
        System.out.println("总计 (Total): " + total); // 53.73

        // 除法示例
        BigDecimal num1 = new BigDecimal("10");
        BigDecimal num2 = new BigDecimal("3");
        // BigDecimal result = num1.divide(num2); // 会抛出 ArithmeticException，因为结果是无限循环小数
        BigDecimal resultRounded = num1.divide(num2, 5, RoundingMode.HALF_UP);
        System.out.println("10 / 3 (保留5位小数, 四舍五入): " + resultRounded); // 3.33333
    }
}
```

## 2.4 `java.util.Random` 类

`Random` 类用于生成伪随机数。

### 2.4.1 常用构造器

| 构造器签名          | 功能描述                                                     | 参数说明                                                     |
| :------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `Random()`          | 创建一个新的随机数生成器。其种子是根据当前系统时间设置的，确保每次运行产生的序列不同。 | -                                                            |
| `Random(long seed)` | 使用单个 `long` 种子创建一个新的随机数生成器。               | `seed`：初始种子。如果使用相同的种子，则每次生成的随机数序列都是相同的，这对于测试和可复现性很有用。 |

### 2.4.2 常用成员方法

| 方法签名                       | 功能描述                                                     | 参数说明                              |
| :----------------------------- | :----------------------------------------------------------- | :------------------------------------ |
| `boolean nextBoolean()`        | 返回下一个伪随机的、均匀分布的 `boolean` 值。                | -                                     |
| `void nextBytes(byte[] bytes)` | 生成随机字节并将其置于用户提供的 `byte` 数组中。             | `bytes`：用来填充随机字节的字节数组。 |
| `double nextDouble()`          | 返回下一个伪随机的、在 `0.0` (含) 和 `1.0` (不含) 之间均匀分布的 `double` 值。 | -                                     |
| `float nextFloat()`            | 返回下一个伪随机的、在 `0.0f` (含) 和 `1.0f` (不含) 之间均匀分布的 `float` 值。 | -                                     |
| `double nextGaussian()`        | 返回下一个伪随机的、呈高斯 (“正态”) 分布的 `double` 值，其平均值是 `0.0`，标准差是 `1.0`。 | -                                     |
| `int nextInt()`                | 返回下一个伪随机的、均匀分布的 `int` 值 (在其整个范围内，包括负数)。 | -                                     |
| `int nextInt(int bound)`       | 返回一个伪随机的、在 `0` (含) 和指定值 `bound` (不含) 之间均匀分布的 `int` 值。 | `bound`：上限 (必须为正数)。          |
| `long nextLong()`              | 返回下一个伪随机的、均匀分布的 `long` 值 (在其整个范围内，包括负数)。 | -                                     |
| `void setSeed(long seed)`      | 使用单个 `long` 种子设置此随机数生成器的种子。               | `seed`：要设置的种子。                |

*   **`java.util.concurrent.ThreadLocalRandom` (自 JDK 7 起)**：在多线程环境下，`ThreadLocalRandom` 通常比共享的 `Random` 实例具有更好的性能，因为它减少了线程间的竞争。使用方式：`ThreadLocalRandom.current().nextInt(bound)`。
*   **`java.security.SecureRandom`**：提供加密强度高的随机数生成器，适用于安全敏感的应用。

```java
import java.util.Random;
import java.util.concurrent.ThreadLocalRandom;

public class RandomDemo {
    public static void main(String[] args) {
        Random random1 = new Random(); // 使用当前时间作为种子

        System.out.println("Random 实例 (默认种子):");
        System.out.println("  随机整数 (0-99): " + random1.nextInt(100));
        System.out.println("  随机 double [0.0, 1.0): " + random1.nextDouble());
        System.out.println("  随机 boolean: " + random1.nextBoolean());

        Random random2 = new Random(12345L); // 使用固定种子
        System.out.println("\nRandom 实例 (固定种子 12345L):");
        System.out.println("  第一个随机整数: " + random2.nextInt(100));
        System.out.println("  第二个随机整数: " + random2.nextInt(100));

        // ThreadLocalRandom 示例 (推荐用于多线程)
        System.out.println("\nThreadLocalRandom:");
        System.out.println("  随机整数 (0-9): " + ThreadLocalRandom.current().nextInt(0, 10)); 
    }
}
```
