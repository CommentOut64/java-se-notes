## 1. Lambda 表达式

Lambda 表达式是 Java 8 引入的一个核心特性，它允许你将**函数（一段代码）作为方法参数传递**。本质上，它是一个**匿名的、可传递的函数**。

**传统方式（使用匿名内部类）：**
```java
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("一个新线程正在运行...");
    }
}).start();
```
这段代码的核心其实只有 `System.out.println(...)` 这一行，但我们却写了很多样板代码。

**Lambda 方式（简洁优雅）：**

```java
new Thread(() -> System.out.println("一个新线程正在运行...")).start();
```
Lambda 表达式极大地简化了代码，使其更易读、更专注于业务逻辑。

## 2. 函数式接口 (Functional Interface)

Lambda 表达式无法独立存在，它必须被赋值给一个**函数式接口**类型的变量。

*   **定义**：一个**有且仅有一个抽象方法**的接口，就是函数式接口。
*   **注解**：`@FunctionalInterface` 注解不是必需的，但强烈推荐使用。它会告诉编译器去检查这个接口是否真的只包含一个抽象方法，如果不是，编译器会报错。

**示例：**

```java
@FunctionalInterface
public interface Calculator {
    int calculate(int a, int b); // 这是该接口唯一的抽象方法
}

public class TestCalculator {
    public static void main(String[] args) {
        // 使用 Lambda 表达式来实现 calculate 方法
        Calculator add = (x, y) -> x + y;
        Calculator subtract = (x, y) -> x - y;

        System.out.println("和: " + add.calculate(10, 5));      // 输出: 15
        System.out.println("差: " + subtract.calculate(10, 5)); // 输出: 5
    }
}
```
Lambda 表达式 `(x, y) -> x + y` 的参数列表 `(x, y)` 和返回类型（`int`）与 `Calculator` 接口的抽象方法 `calculate(int a, int b)` 匹配，因此它可以被赋给 `Calculator` 类型的变量。

## 3. Lambda 表达式的语法

Lambda 表达式的核心语法是 `(参数列表) -> { 方法体 }`。

*   `()`：用于声明参数列表。
*   `->`：Lambda 操作符，读作 "goes to"。
*   `{}`：用于定义方法体。

**语法精简规则：**

1.  **参数类型可省略**：编译器可以根据函数式接口的定义自动推断参数类型。
    
    ```java
    // 完整版: (int a, int b) -> { return a + b; }
    Calculator add = (a, b) -> { return a + b; };
    ```
2.  **单个参数时，括号可省略**：
    
    ```java
    @FunctionalInterface
    interface Greeter { void sayHello(String name); }
    
    // 完整版: (String name) -> { System.out.println("Hello, " + name); }
    Greeter g = name -> { System.out.println("Hello, " + name); };
    ```
3.  **方法体只有一句时，大括号和 `return` 可省略**：
    
    ```java
    // 完整版: (a, b) -> { return a + b; }
    Calculator add = (a, b) -> a + b; // 极其简洁
    ```
4.  **无参数时，括号不可省略**：
    ```java
    // Runnable 接口的 run() 方法没有参数
    Runnable r = () -> System.out.println("Hello");
    ```

## 4. 方法引用与构造器引用

方法引用是 Lambda 表达式的一种**语法糖**，它可以让代码变得更加简洁。当你想要执行的 Lambda 操作**已经有现成的方法可以实现**时，就可以使用方法引用。

| 类型                   | 语法                   | 等价的 Lambda                         |
| :--------------------- | :--------------------- | :------------------------------------ |
| **静态方法引用**       | `类名::静态方法名`     | `(args) -> 类名.静态方法名(args)`     |
| **实例方法引用**       | `对象实例::实例方法名` | `(args) -> 对象实例.实例方法名(args)` |
| **特定类型的方法引用** | `类名::实例方法名`     | `(obj, args) -> obj.实例方法名(args)` |
| **构造器引用**         | `类名::new`            | `(args) -> new 类名(args)`            |

**示例：**

```java
import java.util.Arrays;
import java.util.List;
import java.util.function.Supplier;

public class MethodReferenceTest {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

        // 1. 静态方法引用
        // Lambda:  str -> Integer.parseInt(str)
        names.stream().map(Integer::parseInt); // 假设 names 是 ["1", "2", "3"]

        // 2. 实例方法引用
        // Lambda:  name -> System.out.println(name)
        names.forEach(System.out::println);

        // 3. 特定类型的方法引用 (String 类的 toUpperCase 方法)
        // Lambda:  str -> str.toUpperCase()
        names.stream().map(String::toUpperCase).forEach(System.out::println);

        // 4. 构造器引用
        // Lambda:  () -> new ArrayList<>()
        Supplier<List<String>> listFactory = ArrayList::new;
        List<String> newList = listFactory.get();
    }
}
```

## 5. 变量作用域

Lambda 表达式可以访问其外部作用域中的变量，但有一个重要限制：它只能访问 **`final` 或事实上的 `final` 变量**。

*   **事实上的 `final` (Effectively Final)**：指一个变量在初始化后，其值再也没有被改变过。

```java
public class ScopeTest {
    public static void main(String[] args) {
        String greeting = "Hello"; // 这是一个事实上的 final 变量

        Runnable r = () -> {
            // 可以访问 greeting
            System.out.println(greeting + ", Lambda!");
        };

        r.run();

        // 如果在这里尝试修改 greeting，上面的 Lambda 表达式将会编译失败
        // greeting = "Hi"; 
    }
}
```
这个限制是为了防止在多线程环境下出现数据同步问题。

## 6. 使用 Lambda 实现 `Comparator`

`Comparator` 是一个函数式接口（其抽象方法是 `compare()`），非常适合使用 Lambda 表达式。

**未使用 Lambda：**

```java
import java.util.Collections;
import java.util.List;
import java.util.ArrayList;

List<String> names = new ArrayList<>(List.of("Charlie", "Alice", "Bob"));

Collections.sort(names, new Comparator<String>() {
    @Override
    public int compare(String a, String b) {
        return a.compareTo(b);
    }
});
```

**使用 Lambda：**
```java
List<String> names = new ArrayList<>(List.of("Charlie", "Alice", "Bob"));

// 1. 使用 Lambda 表达式
Collections.sort(names, (a, b) -> a.compareTo(b));

// 2. 使用方法引用，更加简洁
Collections.sort(names, String::compareTo);

System.out.println(names); // 输出: [Alice, Bob, Charlie]
```
