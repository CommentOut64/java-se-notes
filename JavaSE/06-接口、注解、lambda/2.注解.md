## 1. Java 注解 (Annotation)

### 1.1. 什么是注解？

注解`Annotation`是 Java 提供的一种**元数据 (Metadata)**，它本身不直接影响代码的执行，但可以为代码提供额外的信息。

### 1.2. 注解的作用

1.  **提供信息给编译器**：编译器可以利用注解来发现错误或抑制警告。最典型的例子就是 `@Override`。
2.  **提供信息给开发工具**：一些开发工具和代码分析器可以利用注解来生成代码、文档或其他文件。
3.  **提供信息给运行时环境**：程序可以在运行时通过**反射 (Reflection)** 机制读取注解信息，从而执行相应的逻辑。这是许多框架(如 Spring、JUnit)工作的核心。

## 2. 常见的内置注解

| 注解                    | 作用                                                         | 应用位置                   |
| :---------------------- | :----------------------------------------------------------- | :------------------------- |
| **`@Override`**         | 标记一个方法是用来**重写**父类或父接口中的方法。如果方法签名不匹配，编译器会报错。 | 方法                       |
| **`@Deprecated`**       | 标记一个元素(类、方法等)已经**过时**，不推荐再使用。使用时编译器会发出警告。 | 类、方法、字段等           |
| **`@SuppressWarnings`** | **抑制编译器警告**。可以精确地告诉编译器忽略哪些类型的警告。 | 类、方法、字段、局部变量等 |

**示例：**

```java
public class Animal {
    public void eat() {
        System.out.println("动物在吃东西");
    }

    @Deprecated
    public void oldMove() {
        System.out.println("这是一个过时的方法");
    }
}

class Dog extends Animal {
    // 1. 使用 @Override 确保正确重写
    @Override
    public void eat() {
        System.out.println("狗在啃骨头");
    }

    public void test() {
        // 2. 使用 @Deprecated 的方法，编译器会给出警告
        oldMove();

        // 3. 使用 @SuppressWarnings 抑制“未使用”和“过时”的警告
        @SuppressWarnings({"unused", "deprecation"})
        int unusedVariable = 10;
        oldMove();
    }
}
```

## 3. 元注解：注解的注解

元注解(Meta-Annotation)是专门用来**修饰其他注解**的注解。通过它们，我们可以控制自定义注解的行为。

### 3.1. `@Target`：定义注解的应用位置

`@Target` 用于指定一个注解可以被应用在哪些代码元素上(如类、方法、字段等)。

它的值是 `ElementType` 枚举数组，常用值包括：
*   `ElementType.TYPE`：类、接口、枚举
*   `ElementType.FIELD`：字段(成员变量)
*   `ElementType.METHOD`：方法
*   `ElementType.PARAMETER`：方法参数
*   `ElementType.CONSTRUCTOR`：构造器

**示例：**
```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Target;

// 这个注解只能用于修饰方法
@Target(ElementType.METHOD)
public @interface ForMethodOnly {
}
```

### 3.2. `@Retention`：定义注解的生命周期

`@Retention` 用于指定一个注解能够保留到哪个阶段。

它的值是 `RetentionPolicy` 枚举，有三个选项：
*   `RetentionPolicy.SOURCE`：注解只保留在源代码(`.java` 文件)中，编译后被丢弃。主要用于给编译器提供信息，如 `@SuppressWarnings`。
*   `RetentionPolicy.CLASS`：注解保留到字节码(`.class` 文件)中，但在运行时对虚拟机不可见。**这是默认策略**。
*   `RetentionPolicy.RUNTIME`：注解保留到运行时，可以通过反射机制读取。这是框架开发中最常用的策略。

**示例：**
```java
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;

// 这个注解在运行时也能被访问到
@Retention(RetentionPolicy.RUNTIME)
public @interface MyRuntimeAnnotation {
}
```

## 4. 自定义注解

了解了元注解后，我们就可以创建自己的注解了。定义注解使用 `@interface` 关键字。

### 4.1. 标记注解 (Marker Annotation)

最简单的注解是不包含任何成员的注解，它只起到一个标记作用。

```java
// 定义一个用于标记“待办事项”的注解
public @interface Todo {
}

// 使用标记注解
@Todo
public class MyClass {
    // ...
}
```

### 4.2. 带成员的注解

注解可以包含成员，也称为**属性**。其声明方式类似于接口中的方法。

```java
import java.lang.annotation.*;

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface TestInfo {
    // 定义一个名为 author 的字符串成员，并提供默认值
    String author() default "Anonymous";

    // 定义一个名为 priority 的整型成员
    int priority();

    // 如果成员名为 value，在使用时可以省略 "value="
    String value();
}
```

**使用带成员的注解：**
```java
public class MyTestCases {

    @TestInfo(priority = 1, value = "这是一个登录测试")
    public void testLogin() {
        // ...
    }

    // 使用了 author 的默认值 "Anonymous"
    @TestInfo(priority = 2, value = "这是一个注销测试")
    public void testLogout() {
        // ...
    }
}
```
> **注意**：
> *   注解的成员类型只能是基本数据类型、`String`、`Class`、`enum`、`Annotation` 或以上类型的一维数组。
> *   如果一个成员被 `default` 关键字指定了默认值，那么在使用该注解时可以不为这个成员赋值。
