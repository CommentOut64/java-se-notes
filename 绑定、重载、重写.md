

### 1. **静态绑定（Static Binding）**

- **绑定时机**：在 **编译期** 确定方法调用关系。

- 适用情况：

  - **静态方法（static methods）**
  - **私有方法（private methods）**
  - **final 方法（final methods）**
  - **方法重载（Method Overloading）**

- **调用方式**：直接根据 **引用变量的类型** 绑定方法。

  ```java
  class Parent {
      static void staticMethod() {
          System.out.println("Parent's static method");
      }
  }
  
  class Child extends Parent {
      static void staticMethod() {
          System.out.println("Child's static method");
      }
  }
  
  public class Test {
      public static void main(String[] args) {
          Parent p = new Child();
          p.staticMethod();  // 输出: Parent's static method
      }
  }
  ```

  `staticMethod()` 是静态方法，属于 **类级别**，所以绑定发生在 **编译期**，根据 `p` 的 **声明类型（Parent）** 调用 `Parent` 的 `staticMethod()`，而不是 `Child` 版本。

------

### 2. **动态绑定（Dynamic Binding）**

- **绑定时机**：在 **运行期** 根据实际对象的类型进行绑定。

- 适用情况：

  - **方法重写（Method Overriding）**

- **调用方式**：通过 **对象的实际类型** 绑定方法，而不是引用变量的类型。

  ```java
  class Parent {
      void show() {
          System.out.println("Parent's show method");
      }
  }
  
  class Child extends Parent {
      void show() {
          System.out.println("Child's show method");
      }
  }
  
  public class Test {
      public static void main(String[] args) {
          Parent p = new Child();
          p.show();  // 输出: Child's show method
      }
  }
  ```

  `show()` 是 **非静态方法**，适用于 **方法重写（Overriding）**，所以在 **运行时** 根据 `p` 指向的 **实际对象类型（Child）** 调用 `Child` 版本的 `show()`，即 **动态绑定**。

------

### **总结**

|                  | **静态绑定（Static Binding）**                        | **动态绑定（Dynamic Binding）** |
| ---------------- | ----------------------------------------------------- | ------------------------------- |
| **绑定时机**     | 编译期                                                | 运行期                          |
| **适用于**       | `static` 方法、`private` 方法、`final` 方法、方法重载 | 方法重写                        |
| **方法调用依据** | **引用变量的类型（看声明）**                          | **对象的实际类型（看构造器）**  |

### 3. **方法重载（Overloading）**

- **定义**：同一个类中定义多个方法，具有相同的方法名，但参数列表不同（参数个数、类型、顺序至少有一项不同）。

- **用途**：让同一个方法名可以处理不同类型或数量的参数，从而提供多种实现方案。

- **多态类型**：属于**编译时多态（静态多态）**，在编译期根据参数列表确定调用哪个方法。

- **参数与返回值**：参数列表必须不同，返回类型可以不同，但仅凭返回类型不能构成重载；方法签名必须不同。 

  ```java
  public class OverloadExample {
      // 重载方法：参数个数不同
      public int add(int a, int b) {
          return a + b;
      }
  
      // 重载方法：参数类型不同
      public double add(double a, double b) {
          return a + b;
      }
  
      // 重载方法：参数顺序不同
      public String add(String a, int b) {
          return a + b;
      }
  
      public static void main(String[] args) {
          OverloadExample ex = new OverloadExample();
          System.out.println(ex.add(2, 3));          // 输出 5
          System.out.println(ex.add(2.5, 3.5));        // 输出 6.0
          System.out.println(ex.add("Number: ", 5));   // 输出 Number: 5
      }
  }
  
  ```

  

### 4. **方法重写（Overriding）**

- **定义**：子类重新定义父类中已经存在的方法，其方法名、参数列表和返回类型（或其子类型）都必须保持一致。

- **用途**：让子类提供父类方法的具体实现，从而实现运行时的动态绑定和多态。

- **多态类型**：属于**运行时多态（动态多态）**，在运行时根据实际对象的类型来确定调用哪个方法。

- **参数与返回值**：参数列表必须完全相同，返回类型必须相同或是父类返回类型的子类型（协变返回类型）。

- **静态方法无法重写**

  ```java
  class Parent {
      void display() {
          System.out.println("Parent display");
      }
  }
  
  class Child extends Parent {
      // 重写 Parent 类的 display 方法
      @Override
      void display() {
          System.out.println("Child display");
      }
  }
  
  public class OverrideExample {
      public static void main(String[] args) {
          Parent obj = new Child(); // 向上转型：实际对象类型为 Child
          obj.display();            // 运行时调用 Child 的 display 方法，输出 "Child display"
      }
  }
  
  ```

  ```java
  import java.util.*;
  
  public class s9
  {
      public static void main(String[] args)
      {
          Scanner in = new Scanner(System.in);
          int n = in.nextInt();
          int reversed = 0;
          int tmp = 0;
          int sum = 0;
          while (n > 0)
          {
              tmp = n % 10;
              sum += tmp;
              reversed = reversed * 10 + tmp;
              n /= 10;
          }
  
          System.out.println(reversed);
          System.out.print(sum);
      }
  }
  ```
