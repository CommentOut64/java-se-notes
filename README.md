# JavaSE 个人学习笔记

## 项目简介
本仓库为**基于尚硅谷 Java 系列课程**整理的个人学习笔记。对原始资料进行了去冗余处理、补充必要知识点并优化目录结构，目的是为有一定基础的学习者提供一份结构清晰、便于复习的知识汇总与代码示例集。

## 目录结构
```
01-变量和运算符
02-流程控制语句
03-数组
04-类及成员
05-面向对象的特征
06-接口、注解、lambda
07-异常处理
08-多线程
09-常用类与基础API
10-集合框架
11-泛型
12-Swing
```
